WX → WEB / CONVERTER 0.1

把小游戏包转换为
可交付的网页运行包。

提交主包、分包与引擎插件。获取任务进度、兼容性报告和 Web ZIP。

当前适配 Cocos Creator 3.5.1。构建完成后仍需浏览器玩法验收；不是所有微信游戏都能一键转换。

01 · 准备输入

input.zip
  manifest.json
  game/main.wxapkg
  game/resources.wxapkg
  engine/cocos.wxapkg

manifest 填写 appid、engine_appid 和可选的 ad_free。无广告模式目前仅匹配已验证的寿司游戏版本。

02 · 创建与查询

POST /v1/jobs
Authorization: Bearer <your-api-key>
Content-Type: application/zip

GET /v1/jobs/{id}
GET /v1/jobs/{id}/download
状态含义
queued / running已排队 / 转换中
built_unverified可下载；玩法尚未验收
failed / interrupted查看原因；修正输入后重新提交

03 · 下载并验收

下载 ZIP，解压后执行 node server.cjs。在浏览器测试教学、操作、资源和存档，并阅读 conversion-report.json。

API 不在管理域名运行上传的游戏，也不会自动迁移微信登录、支付和远端服务。

OpenAPI 3.1 接口描述 · 认证 key 由部署管理员提供 · 完整部署说明见 README.md
