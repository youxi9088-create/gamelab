# 验证记录 · 2026-10-19

## 已完成

- 6 项自动测试通过：ZIP 路径越界、额外可执行文件、manifest 类型、有效输入结构、API 鉴权与调用方任务隔离、重启中断标记。
- 真实寿司游戏包经 HTTP POST 创建任务，轮询至 built_unverified，经鉴权下载 ZIP，下载文件 SHA-256 与接口记录一致。
- 本次真实样本解包 1,087 个文件（包括引擎插件容器），恢复 128 个模块；产物包含资源、引擎、浏览器适配、无广告逻辑和转换报告。
- 通过服务输出包独立启动网页：原版 3D 场景显示，键盘移动有效，拾取金币后教学进入解锁钓鱼场阶段。
- API 服务在 127.0.0.1:8770 本地运行；未公开到互联网。

## 已知限制 / 未验证

- 浏览器日志仍出现一条原游戏动画计时器错误：`Cannot read properties of null (reading 'idle')`。本轮场景与控制可运行，但不能声称全流程零错误。
- 没有完成所有关卡、经营闭环和移动端设备验收。每个任务报告默认保留 `gameplay: not_tested`，不会拿样本的手动测试冒充新任务验收。
- 未测试 Docker 镜像构建或 Linux 部署，也未做公网压力测试。
- 未验证其他 Cocos 3.5.1 游戏；其他引擎版本、包装格式和联网能力不在首版承诺范围。
- 无自动采集客户本机游戏缓存功能，调用方必须提供实际游戏包及匹配引擎包。

本地集成测试的详细结果：`test-output/result.json`。测试样本和结果不进入服务发行包。
