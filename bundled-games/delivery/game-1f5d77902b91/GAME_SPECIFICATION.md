# 扫雷大挑战 游戏规格说明书

## 玩法类型

益智 / 扫雷

## 画面维度

2D

## 视角与布局

平面棋盘

## 核心玩法

揭开安全格，按相邻雷数推断并插旗，避开地雷。

## 核心体验

数字推理、风险选择与计时挑战。

## 操作方式

鼠标左键揭开、右键插旗；界面可切换操作模式。

## 游戏流程

选难度—揭开与标记—成功或失败—重试或返回；可刷新继续未完成棋局。

## 内容规模

初级9×9/10雷，中级16×9/40雷，高级30×16/99雷，自定义棋盘。

## 奖励与成长

记录各难度最佳用时。

## 存档方式

浏览器本地保存未完成棋局与最佳成绩。
