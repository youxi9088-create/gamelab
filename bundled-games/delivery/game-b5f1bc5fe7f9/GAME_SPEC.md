# 几何王国 · 游戏规格

品类：放置战斗 / 阵容策略

范围：本地五关规则重建版：原Cocos场景、角色、布阵与战斗；新增金币升级至5级。关卡奖励100金币，升级费用100/150/200/250金币；生命、物理伤害、魔法伤害、防御每级增加基础值的20%。不代表原服务器数值；联网、商业化、其他养成未恢复。

## 操作

- 点击地图骷髅进入布阵
- 点击英雄切换上阵；开始战斗后自动战斗
- 胜利后点击空白返回地图，再点骷髅进入下一关
- 英雄页选择角色，点击升级；金币不足时不能升级。
- 失败后再次挑战，点击另一英雄加入阵容，再开始战斗。

## 玩法

- 2个初始角色，5个单波本地关卡
- 敌方原英雄101的基础数值按0.55至0.95缩放
- 客户端原战斗产生胜负；本地结算幂等发放100金币
- 刷新恢复进度；不提供联网防作弊
- 金币升级与关卡奖励共用本地存档；战斗中禁止升级。
