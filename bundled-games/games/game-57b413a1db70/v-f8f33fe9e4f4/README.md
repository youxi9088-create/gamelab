# 回转寿司餐厅 · 原版网页适配

运行包：web-runtime.zip。解压后执行 `node server.cjs`，默认端口 5760；可设置 PORT=5761。也可使用普通静态 HTTP 服务。
本机试玩：http://127.0.0.1:5761/ 。独立运行服务不依赖微信客户端。
操作：鼠标按住拖动、触屏拖动、WASD 或方向键。

使用本机微信缓存中的 Cocos Creator 3.5.1 原始引擎、业务脚本和资源，增加浏览器兼容层。并非恢复出原始 TypeScript 编辑工程。注册状态：待验收；使用范围未确认。
已验证：场景加载、角色移动、教学推进、拾取金币、解锁钓鱼场、刷新存档恢复。
未验证：完整后续关卡和经营闭环。微信登录、广告及远端服务未启用。
本地包开局为拾取金币后解锁钓鱼场，与用户演示的免费解锁版本存在差异。
