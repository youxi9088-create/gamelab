# 几何王国：本地战役与金币成长

以静态 HTTP 服务托管 `web/`，打开 index.html。依赖现代浏览器、Cocos 2.4.15 发布引擎及随包资源，无需原服务器。存档在当前站点 localStorage 中，不跨设备或预览地址同步。

点击地图骷髅进入布阵，点击英雄卡片增减阵容，再点击开始战斗。失败后再次挑战可以换阵；胜利后点击空白关闭结算，再点击地图按钮进入下一关。五关完成后战役结束。

英雄页选择角色并升级。每关奖励100金币，升至2/3/4/5级分别消耗100/150/200/250金币。生命、物理伤害、魔法伤害、防御每级增加基础值的20%，攻击速度与射程不变。这是本地重建公式，不是原服务端数值。五关总奖励500金币，无法让所有角色升满；没有重复刷奖励、离线收益或额外金币来源。

当前范围为两名角色、五个单波关卡、金币升级和存档。招募、其他养成、社交、支付未实现，主要入口已收起；原资源内仍有锁定装饰和未开放提示，不代表实现。

## 实测

- 独立浏览器上下文完成五关，原英雄页升级、扣款、余额不足和刷新保存通过。
- 独立第五关夹具：一级火女单独上阵真实战败，金币不增加、关卡不推进；点击再次挑战后加入骑士，真实战斗获胜并奖励100金币。夹具不修改用户存档，不能作为前四关推进证据。
- 规则单测覆盖阵容校验、幂等奖励、升级认证、非法英雄、余额不足、战斗中升级拒绝和持久化。
- 证据见 validation/；原版逐帧一致、手机真机、全部养成和跨游戏移植未验证。

## 二次开发

local-campaign.js 可修改关卡、奖励、升级公式、阵容与存档；配置、存储、时钟、ID可注入，已在本游戏浏览器和Node验证。local-config.json 的 heroLevelCosts 是升级费用共同来源。local-features.js 收起未实现入口，依赖原Cocos模块和节点名。runtime-viewport.js 管理竖屏容器。

原战斗、角色动画和UI依赖发布JS、Cocos和原资源，可修改但移植需要拆解适配，未验证跨游戏复用。原作者编辑器工程及原服务端未恢复。资源使用记录与功能验证分别保留。
