## 首页和详情

- `/api/state?view=summary` 提供列表与统计摘要，gzip 后实测约570KB；原全量接口约85MB。
- `/api/state?candidate=<id>` 提供该游戏的完整历史和证据，保留原始字段。
- 业务统计先按全量数据计算，再做传输投影；首页事件列表不用于重新统计总数。
- 轮询10秒，隐藏页暂停，同一客户端不重叠请求；只保留当前详情的缓存。
- 摘要异步刷新，后台失败保留上次成功结果并记录日志，快照过旧时界面提示更新延迟。
- 首次冷生成仍可能需要数秒至十余秒；缓存命中约0.18秒。数据库长写事务尚未解决。

## 图片

- `/api/artifact-images/<artifact-id>/<relative-image>` 仅提供登记产物内的图片，经过管理会话、类型与目录边界检查。
- 列表中的本机试玩图片地址转为同源图片接口；客户端不再请求自己的 localhost/127.0.0.1。
- `?thumb=480` 提供卡片缩略图，背景使用1600像素版本；详情和图库保留原图。
- 缓存目录 `data/ui-thumbnails`，键包含原文件路径、修改时间、大小和目标尺寸，原文件不变。
- 远端缩略图依赖：Pillow 13.0.0，Windows CPython 3.12 amd64。嵌入式Python无pip，部署使用对应官方wheel解包到运行时Lib目录；替换运行时后必须补齐并验证编解码器。

## 统计隔离与验收详情优化
- UI统计使用独立只读Python子进程。首次生成成功才启动新入口，随后每轮生成结束等待10秒刷新；HTTP返回已完成快照并显示年龄。父进程退出后子进程通过stdin EOF退出。错误写data/ui-snapshot-worker.log。
