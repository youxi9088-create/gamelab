# 大鱼吃小鱼2 游戏规格说明书

## 玩法类型

动作 / 海洋竞技 / 生存成长

## 画面维度

2D

## 视角与布局

俯视海洋竞技场，玩家独角鲸、食物、对手和危险生物在同一地图活动，界面显示分数与排名。

## 核心玩法

收集食物增加体量，操纵独角鲸以角撞击对手身体，使用有限能量加速并躲避鲨鱼等威胁。当前对手由本地逻辑控制。

## 核心体验

以移动、朝向和加速时机争取攻击机会，在成长收益与被击败风险之间取舍。

## 操作方式

鼠标指向控制朝向，W或上方向键游动；其余方向键或A/S/D调整方向，按住鼠标或空格加速。触屏通过拖动摇杆移动，按住加速控件加速。

## 游戏流程

进入海域 → 收集食物与成长 → 避险或攻击对手 → 累积分数与探索进度 → 被击败后重生 → 再次挑战。

## 内容规模

包含潮汐摇篮、翡翠森林、鲨鱼沉船、克拉肯王座4种海域主题；探索进度关联分数和远征轮次。包含食物、对手及海洋危险生物。

## 奖励与成长

记录最高分、累计得分、击败数、游玩次数及海域远征进度；成长影响本局竞技表现。当前排名不等同于在线多人排行榜。

## 存档方式

通过浏览器本地存储保存累计成绩和远征数据；战斗中的位置与完整现场不作为可恢复存档，不提供跨设备同步。
