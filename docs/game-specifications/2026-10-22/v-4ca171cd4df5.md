# 防御塔大作战 游戏规格说明书

## 玩法类型

塔防 / 防守 / 升级养成

## 画面维度

2D

## 视角与布局

防御塔与敌人处于同一战斗画面，界面提供部队槽位、塔属性、金币和战斗按钮。

## 核心玩法

围绕防御塔组织防守，启动战斗抵御敌人，战后利用奖励提升塔的属性，再继续挑战。

## 核心体验

通过战前投入与战斗结果形成成长反馈，关注防御塔生命和敌方压力。

## 操作方式

鼠标点击或触屏点击开始战斗、号角、结算确认与防御塔升级等界面按钮。

## 游戏流程

准备防守 → 开始战斗 → 抵御敌人 → 胜利结算 → 领取金币 → 升级防御塔 → 继续挑战。

## 内容规模

包含防御塔、弓箭手或武器配置及3个部队槽位。按波次组织战斗；总波次数、全部兵种及升级上限尚未明确。

## 奖励与成长

胜利获得金币，金币可用于防御塔升级。例如第一波胜利奖励80金币，防御塔从1级升至2级时生命由110提高至165。其余升级价格和收益尚未完整列明。

## 存档方式

浏览器本地保存金币、防御塔等级及相关属性，刷新后恢复。正在进行的战斗是否可原位恢复尚未明确；不提供跨设备同步。
