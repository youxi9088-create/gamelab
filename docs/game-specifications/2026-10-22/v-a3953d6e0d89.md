# 霜原炉火 游戏规格说明书

## 玩法类型

策略 / 冬季生存 / 资源管理

## 画面维度

2D

## 视角与布局

营地示意画面结合资源、居民分工、建筑和时间控制面板。

## 核心玩法

为6位居民分配木材与食物采集工作，调节炉火供暖并升级营地建筑，在昼夜与暴雪中维持健康，争取生存7天。

## 核心体验

在采集、消耗、供暖与升级之间分配有限资源，处理短期生存压力并完成长期建设目标。

## 操作方式

点击分工、炉火档位、建筑升级与时间按钮；可手动推进一小时，或启用自动推进并暂停。

## 游戏流程

分配居民 → 采集资源 → 消耗食物与燃料 → 应对夜晚及暴雪 → 升级建筑 → 推进时间 → 达成七日目标或健康耗尽失败。

## 内容规模

共7天、168小时；6位居民，初始3人采木、3人采食。4种建筑为炉火、庇护所、伐木营地和狩猎屋，均最多3级。夜间产出减半，第3、5、7天下午出现暴雪。

## 奖励与成长

初始木材110、食物70、健康100。建筑升级消耗木材，费用为基础价格乘当前等级：炉火80、庇护所65、伐木营地60、狩猎屋60。炉火提供关闭、普通、强力档位。生存168小时且健康大于0、炉火和庇护所均至少2级才能完整胜利；存活但建设不足获得未完全达成目标的结果。

## 存档方式

当前仅在内存保存本局状态，刷新后新开一局；没有持久进度和跨设备同步。
