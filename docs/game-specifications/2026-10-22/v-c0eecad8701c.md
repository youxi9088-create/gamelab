# 坦克怼坦克 游戏规格说明书

## 玩法类型

动作 / 坦克战斗 / 关卡闯关

## 画面维度

2D

## 视角与布局

俯视战场，竖屏布局；战场同时呈现玩家坦克、敌方坦克、地形和炮弹，界面显示生命、敌人数量与金币。

## 核心玩法

操纵坦克在战场移动，利用走位躲避攻击并击败敌方坦克。清除本关敌人后进入胜利结算；生命耗尽则结束本次战斗。

## 核心体验

在躲避与进攻之间选择行进路线，通过敌人减少、生命变化和结算奖励获得反馈。

## 操作方式

点击开始界面进入游戏，鼠标按住拖动或触屏拖动虚拟摇杆控制方向；结算时点击普通领取及返回按钮。

## 游戏流程

点击开始 → 移动与战斗 → 清除敌人或战败 → 结算 → 返回开始界面 → 继续挑战。

## 内容规模

以关卡组织战斗，敌人数量随关卡增长，并存在同时出场数量限制；固定总关卡数尚未明确。

## 奖励与成长

战斗结算取得金币，通关推进关卡进度。普通领取不要求广告奖励；额外广告增益与复活的可用条件不属于基础流程。升级系统的完整数值尚未明确。

## 存档方式

在当前浏览器本地保存金币和关卡记录，刷新后可恢复这些记录；不保存正在进行的战斗现场，不提供跨设备同步。
