# 采集准入与未准入清单

依据用户提供的《游戏筛选标准》v0.4（2026-11-04）与《游戏规格说明书·准入判断新增字段说明》v0.1（2026-11-04）实现。

三个门槛分别判断非简单换皮、约10分钟累计游玩、目标到反馈再到新目标的基础闭环。门槛结论与机制事实分开，页面初筛与源码核查、试玩质检也分开。任何一条有反证才过滤，未知保留。画面维度及加载等工程故障不构成准入否决。

`controlplane/admission.py`要求模型引用当前页面说明的实际原文，并拒绝缺证据或虚构引文的判定。换皮需指向已存在的可用版本，交互、UI、玩法三项均不变才可否决。短局重玩可以支持累计时长推断，初筛不声称实际玩满十分钟。

采集建议保留原人工选择流程；新增未准入tab，展示来源、门槛原因及证据。过滤记录不能通过、派单或自动选择。待判断仍可人工选择抓取补证据；自动选择新增三门槛初筛达标条件。既有人工决定与历史版本不更改。

每条初筛最多一次120秒调用，无自动重试；调用用量归discovery_admission，不归游戏转换。扫描每次最多补评每站max_games条旧未决建议，不重新抓取其已保存页面。后续取得源码时，新规格由共享提示词补齐十项机制/试玩字段；本轮不自动重跑存量游戏、不把页面结论升级为源码或实测通过。

开发与同步环境：准入6、采集20、规格8，共34项回归通过。采集统计测试的自编造隔离fixture补齐既有单机交付前置记录，未修改生产门禁。远端浏览器以隔离建议验证双tab、原因、引文、禁止操作、方向键切换及390px无横向溢出；浏览器没有写入生产数据。发布结果另记发布说明。
