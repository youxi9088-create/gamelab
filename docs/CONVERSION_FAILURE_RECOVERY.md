# 转换失败的共享处理流程

用户约束（2026-11-03）：任务失败必须沉淀为平台流程能力，不依赖当前聊天逐游戏人工兜底；真实运行和玩法门禁保持不变。

| 故障 | 平台动作 | 收敛与完成条件 |
| --- | --- | --- |
| 本地静态资源缺失 | 从本轮观测路径回源；传输失败使用浏览器通道；可复用同入口、同完整URL、哈希匹配的已采集真实字节 | 字体检查文件头，所有资源检查体积、路径与来源；原验证节点复验，保留原件和历史版本 |
| 原站连接中断 | 保留传输失败证据，与404/410、权限拒绝分开 | 已采集资源缓存不是跨网络自动采集服务；没有真实字节时保持阻塞，不假造成功 |
| DOM游戏入口延迟出现 | 保留初始点击前控件样本，并在最终画面重新采样；无初始点击时用最新可见控件供入口恢复选择 | 入口AI必须执行本轮可见控件的真实交互，再进入采集与离线玩法验证；有菜单不代表完整游戏通过 |
| 截图超时 | 在游戏修改诊断之前识别为验证器基础设施问题；重建本任务验证会话，原操作有限复验一次 | 每运行持久记录重试上限；持续失败保留检查点及platform归属，不让AI反复修改游戏，不跳过截图 |
| 控制接口超时 | Client原有幂等键和有界传输重试；最终异常附带接口路径，分类为control_plane_timeout | 不叠加额外写请求重试，不把控制接口问题归为游戏缺陷；保留任务材料 |
| AI HTTP 400/422 | 将供应商响应映射为固定安全类别：上下文、图片数量、图片格式、不支持参数、模型不可用或未分类拒绝 | 不输出原始供应商正文或凭据，不将请求格式错误当瞬断反复重试；保存实际浏览器进度后等待对应能力恢复 |
| 浏览器关闭超时 | 先优雅退出；超时后在Windows仅终止本任务所拥有的进程树 | 真实父子进程退出测试；不按进程名称清理用户浏览器，不停止其他活动任务 |
| 历史失败续作 | 传递基础设施分类及已执行恢复记录，与当前运行证据分开 | 历史通过不替代本轮验收；不重复已证伪的改游戏方向 |

## 已验证实现

- 本地与远端：基础设施自动恢复、现有修复流程、AI输入、错误分类、平台传输等36项回归；以部署回执为准。
- 延迟DOM控件使用真实浏览器fixture回归：初始无按钮、两秒后出现菜单，最终样本保留按钮且初始样本不被抹去。
- 已打开Last Minute与TurboCrib真实菜单及交互后截图，证明原始DOM入口存在；不把入口跳转通过写成关卡或完整玩法通过。
- 资源恢复缓存精确绑定与篡改检测、Windows真实父子进程清理，均有本地及远端测试。

## 不实施的捷径

不得按游戏名称/ID添加平台分支；不得按资源扩展名直接忽略错误；不得隐藏致命弹窗或伪造接口响应；不得为了状态变绿把任务直接设为review。待验收必须由正常交付流程及实际证据产生。

## 终局回报时序（新增）
- session中间的缺资源失败不立即发送失败snapshot；先在同一会话管理循环内完成既有确定性补抓与原节点复验。只有补抓用尽/终局失败才通知上层，成功则发送真实复验快照。
- 真实浏览器回归覆盖首次missing→缓存真实字节补齐→再次验证→上层收到passed=true；本地及远端均通过。正式备份D:/GameLab/backups/session-terminal-20261103-183458。
- 修复解决的是平台回报时序，不把存在缺口的包直接标为成功。字体原始缺失及必要性门禁仍保留。

## 外层加载器及采集收尾

- Universal来源页RSC已明确提供当前游戏的projectId、revisionId、mode和files时，按公开首方加载器协议生成入口线索。限定来源域与play路径、合法UUID及唯一声明；JSON字面读取，不执行脚本，不处理账号与在线游戏数据。
- 适配协议依据本轮捕获的公开客户端 1txo4rrut0mwb.js：加载器构造 `/api/server/${revision}/index.html`。捕获证据保存在工程父目录 deployment-packages/portal-declared-loader-source.json。静态声明不是可玩结论，后续使用原入口探测和交付门禁。
- 响应体/弹窗收集有界等待，资源快照保留实际已完成字节及 response_collection.timed_out。超时不制造空资源或成功记录。
- 采集CLI超时须在宿主仍存活时终止所拥有的进程树，错误归平台基础设施；真实Windows父子进程退出及挂起响应体保留已完成资源均有回归。

## DOM入口到采集契约的衔接

已经通过实际DOM按钮交互的入口，若源码只匹配通用浏览器，不再默认等canvas超时后才要求AI配置契约。采集器校验本轮 entry-probes 内的非链接交互证据文件、passed、精确URL及绑定标记，自动选择browser-dom并记录源HTML和交互证据摘要。其他引擎不覆盖，路径越界、链接或不匹配证据不能触发。离线运行、交互、刷新及最终交付检查保持原要求。

真实浏览器fixture通过按钮让菜单切到回合界面，证明入口交互通过后按DOM就绪，错误URL/越界证据拒绝。此回归不代表任一生产游戏已完成。
