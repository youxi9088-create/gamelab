# Frontend Design 视觉迭代

目标：游戏复刻中心。发现和试玩页突出真实游戏画面，生产管理页突出状态及操作。保留用户指定的深色紫色基调。

颜色：画布 #101017；导航 #16161F；内容 #1D1D28；正文 #F4F2FA；次要文字 #A9A6B9；强调 #AC8BFA。
字体：中文使用 Microsoft YaHei / PingFang SC；拉丁字体 Segoe UI。标题32–44px，正文14px，辅助12px。全部左对齐。

布局比较：

    方案一：标题 / 文字推荐 + 小截图 / 等尺寸卡片
    方案二：标题 / 大尺寸实机画面 + 简短玩法与操作 / 游戏画廊

采用方案二。上一轮的多层渐变、重复英文眉题和过多技术标签抢占游戏画面，删除它们。深色紫色是用户明确约束，保留；用截图比例、标题层级与操作优先级形成差异，不再增加装饰性数字和图标。

原则：截图不裁断；标题和试玩入口始终可见；版本与生产证据留在详情；状态同时使用颜色和文字；移动端按画面、玩法、操作顺序堆叠；减少动态效果。

验收：桌面截图、390/768px八页溢出检查、搜索空状态、8页导航、两个实际游戏iframe验证。无新增字体网络依赖或虚构游戏素材。
