> 版本 v0.1 ｜ 2026-11-04 ｜ 状态：待评审
> 用途：让规格说明书（从代码反向输出）能够支撑「准入门槛」的机械判断。

## 二、各字段详细说明

### 字段 1：玩法特征签名（→ 门槛一·非换皮）

- **描述什么**：游戏"玩法是什么"的指纹，用于和模板库比对、判断是否换皮。
- **内容要求**：
  1. 核心循环（用户做什么 → 得到什么反馈 → 再做什么）；
  2. 核心交互（玩家的主要操作）；
  3. 核心规则（决定玩法的核心数值 / 状态结构）。
- **提取来源**：代码静态（状态机、主循环、交互监听、核心规则常量）。
- **判断用途**：与模板库已有玩法比对，核心循环/交互/规则实质相同 → 判为换皮。

### 字段 2：单局循环机制（→ 门槛二·完整度）

- **描述什么**："一局"是怎么开始、怎么结束的。
- **内容要求**：① 开始条件（点击开始 / 自动开始）；② 结束条件（倒计时 / 通关 / 失败 / 手动）；③ 有没有"局"的概念（还是连续无限）。
- **提取来源**：代码静态（开始 / 结束 / 结算触发的代码路径）。
- **判断用途**：推断"单局大概多长"。

### 字段 3：重玩循环机制（→ 门槛二·完整度）

- **描述什么**：一局结束后，怎么进入下一局。
- **内容要求**：① 有无"再来一局 / 下一局 / 重开"入口；② 重玩时是否保留状态（分数 / 等级 / 解锁）。
- **提取来源**：代码静态（重开 / 下一局逻辑、存档键）。
- **判断用途**：推断"能不能累计玩下去"。

### 字段 4：驱动力机制（→ 门槛二·完整度）

- **描述什么**：什么让用户想重玩。
- **内容要求**：① 分数累积 / 最高分；② 排名；③ 解锁新内容 / 新关卡；④ 成长 / 养成。
- **提取来源**：代码静态（计分、排行榜、解锁、养成系统）。
- **判断用途**：推断"愿不愿意重玩"。

### 字段 5：目标机制（→ 门槛三·闭环）

- **描述什么**：游戏给用户设定的目标。
- **内容要求**：明确目标是什么（胜利条件 / 通关 / 配额 / 评分等级 / 收集）。
- **提取来源**：代码静态（胜利 / 通关条件、任务 / 配额逻辑）。
- **判断用途**：判断"有没有目标"。

### 字段 6：玩法达成机制（→ 门槛三·闭环）

- **描述什么**：用户通过什么操作 / 规则去达成目标。
- **内容要求**：核心操作 + 规则如何通向目标（操作 → 规则 → 目标达成）。
- **提取来源**：代码静态（核心交互 + 规则逻辑）。
- **判断用途**：判断"目标能否通过玩法达成"。

### 字段 7：反馈机制（→ 门槛三·闭环）

- **描述什么**：达成后给用户什么反馈。
- **内容要求**：分数 / 评级 / 排行 / 结算 / 视觉特效 / 音效等。
- **提取来源**：代码静态（计分 / 评级 / 结算逻辑、UI 反馈）。
- **判断用途**：判断"反馈够不够"。

### 字段 8：延续机制（→ 门槛三·闭环）

- **描述什么**：达成目标后给什么新目标。
- **内容要求**：下一关 / 下一局 / 更高分 / 新内容。
- **提取来源**：代码静态（重开 / 继续 / 下一关逻辑）。
- **判断用途**：判断"有没有后续"。

### 字段 9：动机机制（→ 门槛三·闭环）

- **描述什么**：上述机制组合给用户什么动机。
- **内容要求**：挑战欲 / 成长感 / 成就感（结合字段 4–8 归纳）。
- **提取来源**：代码静态 + 综合推断。
- **判断用途**：判断"有没有继续玩的动力"。

### 字段 10：核心目标达成性（→ 生成质检环节）

- **描述什么**：核心目标能否实测达成。
- **内容要求**：① 核心目标是否**实测可达成**（通关 / 达成核心目标）；② 有无死锁 / 数值崩坏。
- **提取来源**：**运行时实测**（试玩跑通），不能是代码推断或"源码确认"。
- **判断用途**：生成质检（AI 检查 bug/数值 + 试玩修复 → 确保可玩通）。

## 三、准入判定摘要表（呈现格式）

放在规格说明书开头或结尾，每个字段标注提取来源，一眼对照门槛：

| 门槛 | 判定字段 | 提取来源 | 本游戏值 | 判定 |
| --- | --- | --- | --- | --- |
| 非换皮 | 玩法特征签名 | 代码 | … | 达标 / 不达标 / 待定 |
| 完整度 | 单局循环 + 重玩循环 + 驱动力 | 代码 | … | 达标 / 不达标 |
| 闭环 | 目标 / 玩法达成 / 反馈 / 延续 / 动机 | 代码 | … | 达标 / 不达标 |
| 质检 | 核心目标达成性 | 试玩实测 | … | 通过 / 待修 |
