**内容说明**

**玩法类型**

**操作方式**

点击 PLAY → 进入经营界面 → 主菜单可用；
点击 UPGRADE → 扣现金升1级提升收入 → 现金足够；
点击 HIRE STAFF → 雇1名员工+50%收入（上限10） → 现金足够；
点击 STYLE ✨ → 换外观+40%收入（上限20） → 现金足够；
点击 SHOPS → 打开店铺列表购买/切换 → 达到解锁门槛；
点击 MAP → 打开世界地图迁移城市 → 现金达到$1.00M；
点击 SPIN → 转盘抽奖（现金或免费次数） → 有余额或免费次数；
点击 DAILY → 领取每日现金与免费转盘 → 每日一次；
点击 2x → 激活3分钟双倍收入 → 15分钟冷却结束；
点击 ☰ → 打开菜单（设置/说明）。
（以上均实机验证）

**视角与布局**

正面固定视角的单屏店铺内景；世界地图为俯视点位图

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：目标、规则、反馈、激励和下一目标。

**内容说明**

**目标机制**

短期攒钱升级/雇人/换外观；中期按解锁门槛购买下一店铺；长期攒$1.00M迁移下一城市（地图界面显示MOVE $1.00M）。（来源：main.js公式与地图段）

**玩法达成机制**

点击升级/购买/迁移→按公式扣费并提升收入加成（员工+50%、外观+40%、25级翻倍、城市+25%）→达成更高收入与解锁目标。（来源：main.js收入公式段）

**反馈机制**

现金与收入每秒实时刷新；按钮标注费用且余额不足置灰；操作弹出toast提示并播放音效；Lv/Staff/Style/秒收入状态栏即时更新；实测UPGRADE后收入$60→$180/min。（来源：main.js更新段+本轮实测）

**驱动力机制**

6店铺解锁链、每店20级外观收集、城市迁移永久加成、每日streak奖励与现金/收入持续增长构成本地重玩驱动；无排行榜。（来源：main.js BUSINESSES/城市/每日段）

**延续机制**

迁移后新城市费用×8递增形成新目标；每日奖励与免费转盘促成次日回访；加速15分钟冷却促成持续游玩。（来源：main.js城市/每日/加速段）

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**目标、规则与结算数值**

目标：积累现金扩张商业帝国；无失败状态，放置持续增长。收入=店铺基础×等级×2^⌊等级/25⌋×(1+员工×0.5)×(1+外观×0.4)×(1+城市×0.25)×(加速2倍)；升级费=基础价×1.5×1.24^等级；员工费=基础价×15×2.8^人数；外观费=基础价×60×2.6^级数；转盘费=当前总收入×150×1.6^连抽（最低$50，10分钟未抽重置连抽）；迁移费=$1.00M×8^已迁移数。

**已验证流程与未覆盖范围**

实机验证：启动、菜单、PLAY进入、UPGRADE两次（Lv1→3、收入$60→$180/min、扣费反馈）、SHOPS/MAP/SPIN界面打开、DAILY领取（+$900与1次免费转盘）、2x激活（收入翻倍至$360/min）、localStorage存档刷新后Lv3恢复、全程无外部请求。仅源码确认：后续店铺解锁门槛、迁移扣费与重开流程、付费转盘连抽加价、离线收益上限数值。未验证：实际购买后续店铺与迁移城市操作、20级外观全量效果。

## 12. 系统设计

**维度定义**：功能系统及界面流程。

**内容说明**

**玩法系统与相互作用**

店铺系统：6店铺独立等级/员工/外观；顾客系统：自动进店消费离店；员工系统：每名+50%收入；外观系统：21档程序化配色与装饰；城市迁移：重置进度换永久+25%/层加成；每日奖励：streak现金+免费转盘；加速系统：3分钟2x、15分钟冷却；转盘系统：固定12格奖励、连抽加价；离线收益：50%×时长（上限2小时）；本地存档系统。

**界面流程与反馈**

主菜单（PLAY/HOW TO PLAY/SETTINGS）→说明页（GOT IT返回）→设置页（音乐/音效开关、隐私政策链接、删除本地存档、BACK）→经营界面（顶部CASH/INCOME/CITY，店名与外观名，Lv/Staff/Style/秒收入状态栏；底部UPGRADE/HIRE/STYLE；下排SHOPS/MAP/SPIN/☰；右侧DAILY/2x）→SHOPS店铺列表（购买/切换）→MAP世界地图（城市点位、MOVE、BACK TO SHOP）→转盘弹层（SPIN、CLOSE）。

**存档方式**

localStorage键pocketEmpireSave2保存金钱、各店铺等级/员工/外观、当前店铺、城市层数、每日streak、加速与转盘时间及音效设置；在升级、领取每日奖励等操作时写入（实测存储记录随操作变化）；刷新后自动读取并按离线时长结算50%收益（>30秒触发，上限2小时）；实测刷新后Lv3进度恢复。不保存项：未发现。
