# chaos-courier 游戏规格说明书

格式版本：V5.1

仅记录有依据的实现层事实；字段非必填。空白表示代码未披露或未登记，不代表不存在、不可玩或验收通过。

## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：chaos-courier

**玩法类型**

城市驾驶 / 快递与物理破坏

**操作方式**

WASD/方向键驾驶，Space手刹，Shift加速，Click/E按准星投包，鼠标环绕镜头，R翻正/脱困；本轮实际ClockIn、W与R，投掷等未测。

**视角与布局**

原3D第三人称跟车/鼠标环绕视角，菜单显示程序城市全景，右下原小地图。

**画面维度**

3D

**引擎**

原Three.js0.185、原EffectComposer与景深/后处理；原ES模块与程序城市/物理。

**程序语言**

JavaScript ES模块、HTML/CSS

**结论字段**

- `game_summary` = 驾驶原快递面包车在程序城市中取件、送件，并应对交通、碰撞和随机事件；班次8分钟，按原速度小费和混乱奖励结算，包裹会受损。
