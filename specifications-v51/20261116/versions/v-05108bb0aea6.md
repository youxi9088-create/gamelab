# 僵尸派对 游戏规格说明书

规格标准：V5.1

## 1. 基础事实

格式版本：V5.1

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

僵尸派对，2D正面合成炮台塔防。点击购买炮台，同等级炮台拖拽合成，将炮台拖到射击架后自动攻击僵尸。Cocos Creator 2.4.2发布运行时，JavaScript；保留原发布脚本与资源，没有原编辑器项目。依据：原入口、引擎版本、`assets/main/index.4e73c.js`。

## 2. 资源类型

**维度定义**：内容元素类别及其引擎资源格式。

**内容说明**

Cocos发布资源体系：引擎/物理/业务JS、序列化场景与弹窗、图片/图集、Spine骨骼资源与动画、字体、音频及内嵌ConfigData配置。resources.loadDir回调40项成功。原文件类型及哈希见`verification/provenance.json`；不将文件数等同独立角色或动画数量。

## 3. 核心挑战维度

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

主要为策略与成长：合成更高等级炮台、选择部署与购买顺序；输入为点击和拖拽。战斗由炮台自动执行。`core_challenge_type` = [strategy, progression]。依据：MergeLayer/Canon/LevelLayer和真实引导合成部署。

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

点击底部购买按钮；拖一座同等级炮台到另一座上完成合成；拖至上方绿色射击架部署。炮台自动瞄准射击，界面弹窗可普通关闭。实测鼠标，实体触屏与APP适配评价未验证。原1080×1920画幅由等比iframe适配。依据：GuildLayer.refreshTouchPos、MergeLayer、host-fit.js。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

购买/取得低级炮台 → 同等级拖拽合成 → 部署射击架 → 自动射击僵尸 → 金币/经验变化 → 继续购买、合成与晋升。`core_loop` = 购买→合成→部署→自动战斗→资源反馈→再合成。依据：UILayer、GameDataMgr、Canon与5步记录。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

加载MainScene → 引导点击购买两座1级塔 → 拖拽合成2级KV2 → 原解锁弹窗 → 关闭弹窗并部署第12位射击架 → 自动战斗 → 原签到/晋升弹窗分支。刷新后读取本地炮台、金币、经验与引导完成状态并继续运行。本轮没有验证完整晋升领取、全关卡、商店高价购买或失败重开。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

相同等级炮台合成为高一级，MaxMergeLandId记录最高合成等级；战斗累计经验可出现晋升弹窗，UserLevel/UserMaxLevel记录进度。本轮合成1+1→2（KV2），经验0→37，刷新后继续增至78；出现“青铜3”晋升弹窗，但UserLevel仍1，未领取，不写成已完成升段。依据：03-merge-settled.json、04-combat.json、05-reload.json。

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：目标、规则、反馈、激励和下一目标。

**内容说明**

**目标**：合成并部署炮台，攻击僵尸，获得金币/经验并推进装备与段位。

**规则**：同级炮台拖拽合成，高级炮台在射击架自动开火；下方格位用于存放与合成。常规购买消耗金币，教学购买有独立免费分支。

**反馈**：炮台等级与外观、解锁KV2弹窗、枪炮与敌人动画、金币和经验变化、晋升提示。原音频保留，听觉未验证。

**激励**：金币、经验、可合成炮台、原星/装备/段位配置。本轮教学购买未扣金币；部署后金币2000→2175、经验0→37，刷新后战斗继续。

**下一目标**：以战斗资源继续取得炮台、合成并调整部署；本地存档恢复已部署KV2。

`loop_completeness` = 部分（购买、合成、部署、战斗收益及保存实测；金币常规消费、完整晋升和全关卡未覆盖）。依据：业务脚本与5步证据。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

LandIdArr共15个位置；0为空、正数为炮台等级，源码还使用-1箱位状态。真实1级塔两座经普通拖拽合成2级KV2，放置索引12后自动射击。初始教学购买走isGuildOver=false分支，不扣2000金币；不得据此称常规购买免费。源码战斗按敌人/等级配置给金币与经验；未实测失败判定或全部敌人。依据：GameData、UILayer.onBtnClickToQuickBuy、MergeLayer与LevelLayer。

## 10. 数值配置

**维度定义**：影响玩法的生命、概率、时长、速度和经济等数值。

**内容说明**

| 参数 | 已确认事实 |
| --- | --- |
| 开局金币/星 | 2000 / 10 |
| 存放/部署数组 | 15位 |
| 1级炮台 | atk4，rate1.8，speed2000，基础标价150，源码 |
| 2级炮台KV2 | atk10，rate1.3，speed3000，源码；本轮已合成 |
| 合成 | 1+1→2，部署索引12 |
| 战斗观察 | 金币2175、经验37；刷新后继续增长至2467/78 |
| 内容配置 | 50项炮台、31项等级、18项装备卡，仅配置数量 |
| 初始技能 | 闪电/加速/核弹各2，未消费实测 |

依据：ConfigData、GameData、config-counts.json及状态记录。源码速度为内部单位，rate字段不擅自解释为每秒射速。

## 11. 关卡配置

**维度定义**：关卡布局、目标、数量、递进和难度参数。

**内容说明**

ConfigData.levelData有31项记录，canonData50项、cardData18项。等级1配置mapId1、hp1、gold1、levelExp40；这些是配置事实，不代表31关或50种炮台全部实测可达。本轮只部署KV2在初始等级战斗，UserLevel1，晋升提示未领取。依据：ConfigData及verification/config-counts.json。

## 12. 系统设计

**维度定义**：功能系统及界面流程。

**内容说明**

原系统包括炮台购买/合成/部署、自动瞄准开火、僵尸、金币/经验、星、装备库、金库、签到、技能、暂停设置、晋升与本地存档。实测主循环与存档，其他系统以源码存在记录。LandIdArr、UserGold、UserExp、MaxMergeLandId、GuildOver等使用原localStorage键保存；刷新后KV2仍在12位且继续战斗。不提供在线账户或广告服务。

## 13. 主题化包装

**维度定义**：文字、叙事、命名及美术内容。

**内容说明**

金属与机械炮台、僵尸入侵、射击架、军械库、金币/钻石图标、青铜段位及中文UI；原Spine造型、动画与图集保留。没有玩家人物剧情证据，不补写世界观。依据：原资源及03-upgrade.jpg、04-auto-battle.jpg。

## 14. 养成系统 + 经济系统

**维度定义**：成长要素和资源产出、消耗、回收机制。

**内容说明**

金币来自原自动战斗奖励，常规购买与装备配置有消耗；星可用于原加速/自动合成/技能等功能，部分入口另有广告奖励。本轮未扣星，未领签到或广告；普通引导免费取得两座1级塔后合成部署，战斗金币确实增长。最高合成等级与经验保存，常规购买经济循环未完整实测。依据：GameDataMgr与UILayer、5步记录。

## 15. 角色 / 单位设定

**维度定义**：角色单位的数量、属性、能力、定位和关系。

**内容说明**

主要单位为炮台与僵尸。50项炮台等级配置有atk、rate、speed、价格与战力；本轮实测1级和2级KV2。未穷尽敌人类型、攻击差异与全部皮肤，不把配置数量写成已验证角色阵容。依据：ConfigData、Canon、LevelLayer。

## 16. 商业化

**维度定义**：已实现的广告、内购、订阅、买断和付费点。

**内容说明**

原SDK激励接口用于额外金币/星、加速、自动合成等；未确认真实付费流程。本地不联网、不调用激励成功回调，隐藏“观看广告”和主界面广告自动合成按钮；普通金币购买、已有技能、普通关闭与本地签到逻辑保留。SDK pause.show只注册宿主事件，不主动调用暂停回调。依据：local-host.js、SdkMgr、UILayer、各原弹窗。
