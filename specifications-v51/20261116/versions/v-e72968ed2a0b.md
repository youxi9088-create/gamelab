# 指尖投篮 游戏规格说明书

规格标准：V5.1

## 1. 基础事实

**维度定义**：让读者第一眼知道“这是什么类型、什么操控体验的游戏”，以及它的技术栈。

**内容说明**

4k99 848《指尖投篮》，原Cocos发布运行时，2D竖屏。

## 2. 资源类型

**维度定义**：游戏中游戏内容元素的资源类型是什么——即在哪个引擎运行下的资源格式。

**内容说明**

原渐变天空、篮球、篮筐、粉色弹板、关卡号、钥匙图标、球场围栏与地形。 定位：原发布资源与配图。

## 3. 核心挑战维度

**维度定义**：游戏核心玩法主要挑战 / 满足人的什么。

**内容说明**

通过原普通触摸输入驱动弹板将篮球发射向篮筐。

## 4. 操控方式

**维度定义**：操控本身的复杂度 + 需要玩家判断的时机 / 策略复杂度。

**内容说明**

Game.start绑定TOUCH_START/MOVE/END/CANCEL；普通按住触发Game.TouchStart，释放触发TouchEnd。本轮短点击和0.5秒按住释放均为鼠标输入。

## 5. 行为路径

**维度定义**：玩家一局里重复做什么。

**内容说明**

首次加载原指尖篮球开始页、关卡1与钥匙。；普通点击开始，进入原首关弹板、篮球和篮筐。；普通短点击投篮机关；后续截图篮球仍接近弹板，不宣称本步已成功入篮。；普通按住并释放原投篮区域0.5秒，原弹板转起、篮球飞到左上方；没有通关或新增分数证据。；第5步重载，不宣称关卡进度或钥匙保存。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从开始到结束的流程 + 每个关键节点的潜在流失风险点。

**内容说明**

第3步短点击后球仍接近弹板；第4步普通按住并释放0.5秒，原粉色弹板转起，篮球从下方约y570飞到左上约y180，篮网出现形变。未宣称进球或通关，第5步重载。

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：游戏是否具备“明确目标 → 明确规则 → 达成反馈 → 奖励激励 → 下一目标”的完整闭环。

**内容说明**

目标为把原篮球送向篮筐；按住/释放使原弹板旋转→原刚体碰撞和抛球→篮球位置与篮网画面反馈→继续尝试投篮。本轮未取得通关、钥匙或奖励证据，因此这些激励不计已验证。

## 9. 玩法规则

**维度定义**：核心循环、玩法规则、目标与进度。

**内容说明**

assets/main/index.fc10f.js:Game.TouchStart在未结束状态把BallNode刚体设为Dynamic、清零球角速度，再把GroundNode刚体角速度设为800；TouchEnd将弹板角速度设为-300。篮球由原物理模拟被弹板抛起；onGameEnterScore负责原进筐后场景机构处理。本轮只验证弹板转起和篮球飞到左上，未验证入筐判定或胜利。

**维度定义**：影响玩法的关键数值。
