# 超级弹球大师 游戏规格说明书

规格标准：V5.1

## 1. 基础事实

格式版本：V5.1

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

游戏名：超级弹球大师。2D正面固定球场，鼠标按住拖动瞄准、松开发射弹球击打数字块。原包为 Cocos Creator 2.4.7 的 JavaScript 发布运行时；未取得原 TypeScript 源码或 Cocos 编辑器工程。依据：`src/settings.9239a.js`、`assets/main/index.dc5f5.js`、实机记录。

## 2. 资源类型

**维度定义**：内容元素类别及其引擎资源格式。

**内容说明**

Cocos发布资源体系：引擎JS、业务JS、序列化JSON、原图片/图集、字体、音频和粒子配置。资源包声明855个路径；loadDir回调成功取得855项资产。原文件扩展名统计见 `verification/resource-facts.json`，文件数不等于独立美术数量。`engine_asset_system` = Cocos。

## 3. 核心挑战维度

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

主要是操控：调整发射角度并利用碰撞反弹；次要是策略：根据数字和位置选取击打路径。`core_challenge_type` = [operation, strategy, challenge]。依据：GameArea、ObjBlockSquare、BBall模块与真实发射记录。

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

球场按住、拖动、松开进行瞄准发射；点按菜单选择关卡或模式，暂停窗口提供音乐、音效、返回主页和普通重开。实测鼠标；实体触屏、手柄与APP适配结论未验证。原1080×1920画幅通过固定尺寸iframe等比适配，保持游戏启动时的原设计尺寸。依据：`host-fit.js`、`verification/02-after-shot.json`。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

观察方块数字与布局 → 拖动瞄准 → 松开发球 → 反弹命中、数字变化与消除 → 球回收、下一轮布局 → 再次发射。`core_loop` = 观察→瞄准→发射反弹→反馈→下一轮。依据：业务GameArea/ObjManager模块和首关、经典模式两次真实发射。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

加载 → BallGameHall菜单 → BallCheckPoint关卡选择 → BallGameScene对局；也可从菜单直接进入经典模式或百球模式。暂停弹窗可普通重开或返回主页。本轮首关一次发射360分，普通重开归零；经典一次发射10分后返回。未完成通关/失败结算，不填写节点耗时和流失评价。依据：verification与screenshots。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

代码包含关卡解锁、星级、经典/百球最高分与球样式数据。本轮只验证第一关操作与经典模式发射；未通关、未验证解锁或全部成长。刷新后经典最高分从10恢复0，不能宣称该最高分已持久化。依据：UserInfo.gdata、ResultWindow、`verification/04-before-reload.json`、`05-after-reload.json`。

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：目标、规则、反馈、激励和下一目标。

**内容说明**

**目标**：击打数字块，推进关卡或提高当前模式分数。

**规则**：拖动瞄准后释放弹球，球与墙及块碰撞反弹；数字块随命中变化，消除与分数显示提供反馈，剩余块在轮次推进中改变布局。

**反馈**：原弹球运动、数字/分数、消除与进度条；音频资源保留，未验证实际听觉。

**激励**：当前局分数；原包还包含星级、关卡、钻石和球样式配置，未实测其完整获取/消费。

**下一目标**：回收后继续发射，或普通重开重新挑战。实测首关0→360、普通重开360→0、经典0→10。

`loop_completeness` = 部分（核心发射计分与普通重开已验证，通关/失败结算未覆盖，最高分持久化有原包限制）。依据：业务脚本与5步记录。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

首关实际30球，经典模式初始1球。数字块被击打后数字与分数变化，存在加球、三角块和特殊块。源码实现警戒/结束边界与ResultWindow，但本轮未到达结算；不把代码分支写成实测通过。普通重开重置当前关卡分数。依据：BBall、GameArea、ObjBlockSquare、ObjBlockTriangle、WarnLine、GameOverLine及真实记录。

**内容说明**

## 11. 关卡配置

**维度定义**：关卡布局、目标、数量、递进和难度参数。

**内容说明**

原resources包声明500个普通地图配置路径和10个百球地图配置路径，保留原JSON。关卡选择页首屏显示01—40；本轮只进入第1关。地图路径数量不能作为全部可玩、全部通过或“上千关”的证明，不采用站点营销数字。依据：`verification/resource-facts.json`及原config。

## 12. 系统设计

**维度定义**：功能系统及界面流程。

**内容说明**

功能包括菜单、关卡选择、弹球碰撞、数字/特殊块、计分、暂停、普通重开、音量设置、球样式商店、本地存储。音乐设置0与音效1刷新保留；经典最高分仅在本轮内更新，刷新恢复0。原updateGameUserData只整理对象并回调，不向在线账户保存。未验证商店购买与完整结算。依据：BallGameHall、AudioManager、UserInfo、Storage与5步记录。

## 13. 主题化包装

**维度定义**：文字、叙事、命名及美术内容。

**内容说明**

蓝色渐变球场、彩旗背景、彩色带数字的几何块、弹球与钻石/商店/暂停图标，原中文标题、字体与美术保留。没有人物叙事证据，不补写世界观或剧情。依据：原资源与screenshots。

## 14. 养成系统 + 经济系统

**维度定义**：成长要素和资源产出、消耗、回收机制。

**内容说明**

源码包含钻石余额、四类道具和球样式商店；本轮余额0，未实测产出、购买和消费回路。原浏览器分享入口会直接赠300钻石，该入口已隐藏，不伪造分享或广告收益。存档字段与经济可达性分开记录。依据：BallGameHall.diamondPlusCallBack、UserInfo.bagData与local-host.js。

## 15. 角色 / 单位设定

**维度定义**：角色单位的数量、属性、能力、定位和关系。

**内容说明**

无人物阵容。玩法单位为弹球，交互对象包括数字方块、三角块、加球对象与特殊消除块；源码还包含其他块类型，未穷尽。未将球外观解释成未经证实的技能。依据：BBall、ObjBlock*、真实经典场景。

## 16. 商业化

**维度定义**：已实现的广告、内购、订阅、买断和付费点。

**内容说明**

原MINI_GAME_SDK激励视频接口用于加球、奖励或广告重玩；本地不联网、不触发成功奖励回调，隐藏相应广告按钮与分享/退出入口，保留普通游戏和普通重开。在线账号、排行、充值与联机不作为本地交付功能。依据：local-host.js、BallGameHall.showAdsReward、BallGameScene.addBall、ResultWindow.onAdReplayHandler。
