# TurboCrib 游戏规格说明书

格式版本：V5.1

仅记录有依据的实现层事实；字段非必填。空白表示代码未披露或未登记，不代表不存在、不可玩或验收通过。

## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：TurboCrib

**玩法类型**

卡牌对战游戏（Cribbage变体）

**操作方式**

1. 点击手牌 → 选中/取消弃牌或出牌 → 弃牌阶段需恰好选中2张
2. 点击SUBMIT DISCARD → 提交弃牌入crib → 须已选2张
3. 点击手牌 → pegging阶段打出该牌 → 须Your Turn且累计不超31
4. 点击CALL GO → 宣告无法出牌让对手得分 → 无可出牌时出现
5. 点击COUNT HAND/COUNT CRIB → 进入对应计分 → 计分阶段出现
6. 点击Declare → 宣告Joker/特殊牌面值 → 持未赋值牌时出现
7. 点击RETURN TO GAME → 恢复存档对局 → 存在进行中存档时显示

**视角与布局**

固定俯视牌桌视角

**画面维度**

2D

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

**核心玩法**

与CPU进行TurboCrib纸牌对战：切牌定庄、每轮弃2张入crib、翻UPCARD、pegging阶段轮流出牌累计至31点内得分、GO规则、随后按手牌与crib计分。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

**游戏流程**

开始：菜单选LEVEL与难度、输入名字、PLAY进入切牌定庄；操作：轮流弃牌→翻UPCARD→pegging出牌/GO→手牌与crib计分；结果：分数写入181点轨道；继续：自动发下一手，直到一方达到终点。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

**奖励与成长**

通过累计分数沿181点轨道推进；LEVEL 2及更高策略内容未进入，保留覆盖边界。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**目标、规则与结算数值**

目标：先走完181点轨道获胜。pegging累计不得超31，达15/31、对子、顺子等得分（具体公式未逐项验证）；无牌可出须CALL GO让对手得1分；每手弃2张入庄家crib；Joker需宣告面值；双Joker标准计分。阈值181分已由界面确认。

**已验证流程与未覆盖范围**

实机验证：启动、菜单、切牌、弃牌提交、pegging至30/31+CALL GO计分、Count Hand +9、Count Crib、新一手再弃牌-pegging、刷新恢复。仅源码确认：Joker献祭等扩展规则。未验证：LEVEL 2、多人、Training、登录排行。

## 11. 关卡配置

**维度定义**：关卡布局、目标、数量、递进和难度参数。

**内容说明**

**内容规模**

LEVEL 1（Maiden voyage）与LEVEL 2（Advanced strategy）两个等级、Solo/Multiplayer/Training三种模式、三档CPU难度为固定选项；每手发牌为程序随机。多人与Training未实测。

## 12. 系统设计

**维度定义**：功能系统及界面流程。

**内容说明**

**玩法系统与相互作用**

对象：52+2Joker牌组、UPCARD、crib、peg轨道、双方手牌；状态：切牌/弃牌/pegging/计手/计crib/新一手；触发：选中提交、出牌累计、GO、计分按钮；交互：CPU自动行动、计分日志、Joker宣告、菜单/返回入口。

**界面流程与反馈**

主菜单（等级/模式/难度/名字/PLAY）→切牌界面→牌桌（计分板、弃牌提交、出牌、GO、计分按钮、MENU）；结算后自动进入下一手；刷新后菜单出现RETURN TO GAME可回到对局。

**存档方式**

对局进度写入sessionStorage键turbocrib-game-resume，玩家名与ID写入localStorage；随阶段推进持续更新；刷新后通过RETURN TO GAME恢复到同一对局状态（实机确认PEG 11/31、UPCARD K♠、手牌一致）；不含跨会话的长期战绩（未验证）。
