# 俄罗斯方块2 游戏规格说明书

## 1. 基础事实

格式版本：V5.1

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

4k99/category5/2601，原TetrisJJ-1.2，Cocos3.7.1，1080×1920，双模式卡通方块。

## 2. 资源类型

**维度定义**：内容元素类别及其引擎资源格式。

**内容说明**

原彩色卡通四格方块、落点投影、竖棋盘/下一块、分数/等级/全服最高标签和双模式首页。 原load/tetris场景与SpriteFrame、音频。

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

**核心体验**

经典模式原S形落块、O形下一块；普通点和下拖后底部S/O/折形堆叠与新T形，当前/个人最高均0，等级1。

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

原UI触摸点旋转、横拖左右、向下拖超过原设计180快速落块；原W旋转/S快落/A左/D右有代码，本轮只点与下拖。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

双模式首页→普通经典→普通点→普通下拖堆叠与新块→刷新首页。
