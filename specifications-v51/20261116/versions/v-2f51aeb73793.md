# 极限躲避 游戏规格说明书

## 1. 基础事实

格式版本：V5.1

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

4k99 391《极限躲避》，原独立Cocos2d-JS发布包，原设计540×960，2D竖屏。

## 2. 资源类型

**维度定义**：内容元素类别及其引擎资源格式。

**内容说明**

## 3. 核心挑战维度

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

普通拖动飞机躲避运动弹点，以存活时间计分；原碰撞后自然结算。

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

普通点击原开始/重开，按住飞机从屏幕640,355拖到690,300，原飞机随手势向右上移动。未注入位置、时间或胜负。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

首次加载保留原相邻目录脚本404→静态移除失效重复预载→第2步重载显示原菜单→第3步开始自然碰撞→第4步重开→第5步普通拖动及自然结算。
