# Squadron 游戏规格说明书

格式版本：V5.1

仅记录有依据的实现层事实；字段非必填。空白表示代码未披露或未登记，不代表不存在、不可玩或验收通过。

## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：Squadron

**玩法类型**

动作 / 太空飞行射击

**操作方式**

鼠标转向，W/S或上下箭头调节油门，A/D或左右箭头滚转，Shift加速，左键/Space激光，右键/E锁定导弹，Esc退出控制。当前采用原有非锁定指针回退；本次五步实际操作Fly solo、Space和Esc，未额外验证转向/油门/导弹/手柄。

**视角与布局**

第三人称追尾摄像机；固定顶部任务与倒计时、右上分数/备用船/波次、左下船体/加速/速度和右下导弹状态。

**画面维度**

3D

**引擎**

原生Three.js 0.185；原JS模块可编辑。

**程序语言**

JavaScript ES模块、HTML/CSS、GLSL。

**结论字段**

- `game_summary` = 驾驶单人战机攻击巨型战舰的护盾、机库、舰桥和核心，同时躲避原生敌机与炮塔，在战舰跃迁前完成目标。

## 4. 操控方式

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

**核心玩法**

单人起飞→飞行与激光/导弹攻击→依次解除护盾并攻击关键系统→击杀与破坏计分→船毁消耗备用船重生→跃迁/全灭或核心摧毁决定结果。

**结论字段**

- `core_loop` = 观察HUD与目标标记→飞行/攻击→原命中、伤害与波次更新→选择下一目标或重生继续。

目标：先破坏两处护盾，再攻击机库/舰桥，最后暴露核心；保护战机并在跃迁前完成。规则：原飞行物理、敌机/炮塔、命中伤害、锁定和备用船限制决定结果。反馈：目标标记、激光/敌方炮火、HUD船体与备用船、波次、分数及倒计时；原胜负面板代码保留，本次只验证局内操作/真实受击和刷新。激励：击杀和系统破坏计分、推进核心目标；未声称五步内获胜。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**目标、规则与结算数值**

原跃迁倒计时10分钟；起飞4备用船，实际受击消耗备用船。护盾保护其他关键系统，按原条件开放核心；战舰跃迁或备用船耗尽全灭失败，核心摧毁成功。保留原任务模拟与伤害配置。

**已验证流程与未覆盖范围**

用户每款最多5步：原菜单启动→Fly solo→按住Space1.2秒→Esc退出控制→刷新。实机10:00/4备用船/Wave0起飞，原战场自动推进到Wave1、船体受击并消耗备用船；Space为原激光输入，未据此声称命中或击毁目标，分数仍0。Esc显示CLICK TO TAKE THE CONTROLS及ABANDON MISSION，未点击放弃；刷新回原菜单，未验证本次胜负终局、重开、导弹发射或手柄存档恢复。175原函数/类语义SHA不变，包含ls飞行物理和原单人任务模拟；保留原3D模型、贴图、音频与目标/伤害/波次/10分钟/备用船规则，不改难度。移除真实SDK发现/绑定/发送器、多人房间传输类及朋友/大厅入口；不安装SDK全局，不伪造账号/房间或胜利。选择原有非锁定指针回退，浏览器pointerLockElement不伪造。仅原invertStick设置由实际localStorage保存，任务不跨刷新恢复；本轮未切换该手柄设置。178完整网络事件含两次完整启动，89请求全同源，无截断/外联/脚本异常/console警告错误；仅浏览器自动favicon.ico请求404，非游戏依赖，已用空data图标元数据消除该请求，完整原记录保留且未追加试玩。五步结束，未追加操作。正常原任务入库待人工验收，不批准不供货。
