# 几何王国 游戏规格说明书

规格标准：V5.1

## 1. 基础事实

格式版本：V5.1

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

**玩法类型**

阵容策略 / 自动战斗 / 关卡闯关

**操作方式**

鼠标点击或触屏点击。点击地图骷髅进入布阵，点击英雄切换上阵状态，点击开始战斗；胜利后点击空白返回地图，再点击骷髅继续。

**视角与布局**

侧视战斗，竖屏布局；卡通角色在森林场景中从两侧交战。

**画面维度**

2D

## 3. 核心挑战维度

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

**核心体验**

战前选择队伍，战中通过角色动作、攻击效果、伤害数字和血条获得直观反馈，战后通过关卡推进获得明确目标。操作负担较低，当前两名可用角色提供有限的阵容选择。

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

**核心玩法**

玩家选择上阵英雄，开始战斗后由角色自动移动和攻击，通过伤害与血量变化决定胜负。胜利领取金币并解锁下一关。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

**游戏流程**

进入地图 → 选择关卡 → 配置队伍 → 自动战斗 → 胜利结算 → 返回地图 → 进入下一关。五关完成后战役结束。失败不推进关卡，可再次挑战。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

**奖励与成长**

每关胜利奖励100金币，五关共500金币。同一场战斗不重复发奖。金币当前仅作为累计奖励，没有消费或升级用途。没有离线收益。

**内容规模**

2名初始角色（101和401），最多5个队伍槽位；5个关卡，每关1波敌人。敌方使用角色101，生命、物理及魔法伤害、防御的基础属性倍率依次为0.55、0.65、0.75、0.85、0.95。
