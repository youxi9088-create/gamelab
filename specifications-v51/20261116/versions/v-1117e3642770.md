## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：Play Pocket Empire - Free Online Game | Rosebud

**玩法类型**

放置经营（Idle Tycoon）

**操作方式**

PLAY → 进入经营场景 → 主菜单点击
UPGRADE → 扣款升级店铺提升收入 → 现金足够时点击
HIRE STAFF → 雇佣员工增加收入 → 现金足够时点击（$150起）
STYLE → 更换店铺外观并加成收入 → 现金足够时点击（$600起）
SHOPS → 查看/购买新店铺 → 底部按钮点击
MAP → 打开世界地图迁移城市 → 底部按钮点击
SPIN → 打开幸运转盘抽奖 → 底部按钮点击
CLOSE → 关闭转盘弹窗 → 弹窗内点击
BACK TO SHOP → 返回经营场景 → SHOPS/MAP界面点击

**视角与布局**

俯视固定视角

**画面维度**

2D

**维度定义**：功能系统及界面流程。

**内容说明**

**玩法系统与相互作用**

现金系统（自动增长+界面显示）、升级系统（等级/费用/收入递增）、员工（0/10）与风格（0/20）数值槽、店铺购买链（6店）、城市迁移（12城+永久加成）、幸运转盘（12格奖励）、每日奖励与2x加速入口（内部逻辑未实测）

**界面流程与反馈**

主菜单（PLAY/HOW TO PLAY/SETTINGS）→经营场景（顶部现金/收入/城市，底部升级、雇佣、装饰及SHOPS/MAP/SPIN入口）→MY SHOPS（店铺列表、购买、BACK TO SHOP）/WORLD MAP（城市、MOVE、BACK TO SHOP）/Lucky Wheel弹窗（CLOSE、SPIN）

**存档方式**

localStorage键pocketEmpireSave2保存进度；升级等操作后自动写入；实机验证刷新后PLAY恢复Lv3与$180/min收入，现金离线继续增长（封顶2小时、按50%结算为源码逻辑，未实测触发）；未验证不保存项
