## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：Play Starblade - Free Online Game | Rosebud

**玩法类型**

回合制大战略（4X银河征服）+王朝经营

**操作方式**

点击主菜单按钮 → 进入新战役/读档等 → 实机验证；点击星系 → 选中并打开行星面板 → 实机验证；点击行星面板按钮 → 建造/招募/任命 → 实机验证可见；点击右上角沙漏 → 结束回合推进年份 → 实机验证；点击事件弹窗按钮 → 接受/收养/拒绝等 → 实机验证；底部PLANETS/ARMIES/AGENTS → 切换列表 → 实机验证可见；键盘键位未验证

**视角与布局**

俯视银河星图，可旋转缩放；行星与事件为界面面板

**画面维度**

3D

## 12. 系统设计

**维度定义**：功能系统及界面流程。

**内容说明**

**玩法系统与相互作用**

星系系统（建筑、总督、秩序、收入）；舰队移动与战斗（可战术或自动结算，未实机进入战斗）；王朝系统（继承人、婚姻、收养）；事件系统（效忠、锦标赛、借贷）；末日计数系统

**界面流程与反馈**

主菜单→战役种子→家族选择→星图+教程6步→行星面板/事件弹窗→回合并存档；刷新后CONTINUE直回星图

**存档方式**

localStorage 自动存档（starblades_save，年度触发）+6个手动槽位+索引；刷新后主菜单出现 CONTINUE 并可恢复到 Y3002 状态；已实机验证自动存档跨刷新恢复；设置存于 sb_settings；不保存项未逐项穷举
