# flappybird 游戏规格说明书

规格标准：V5.1

## 1. 基础事实

**维度定义**：让读者第一眼知道“这是什么类型、什么操控体验的游戏”，以及它的技术栈。

**内容说明**

4k99 423《flappybird》，原Cocos发布运行时，2D竖屏。

## 2. 资源类型

**维度定义**：游戏中游戏内容元素的资源类型是什么——即在哪个引擎运行下的资源格式。

**内容说明**

原像素小鸟、树木与草地背景、管道边缘、0分、最佳分、TAP教程与开始按钮。 定位：原发布资源与配图。

## 3. 核心挑战维度

**维度定义**：游戏核心玩法主要挑战 / 满足人的什么。

**内容说明**

普通点击控制原小鸟飞行，避开原管道与地面。

## 4. 操控方式

**维度定义**：操控本身的复杂度 + 需要玩家判断的时机 / 策略复杂度。

**内容说明**

普通点击由原GameScene触摸逻辑调用Bird.onJump；本轮点击一次飞行区域，未修改Bird.velocity。

## 5. 行为路径

**维度定义**：玩家一局里重复做什么。

**内容说明**

首次加载原0分/最佳0、小鸟与开始按钮。；普通点击原开始。；普通点击原飞行区域，原小鸟倾斜飞行，仍0分。；第4步重载回原开始页；累计仅4步，无新增得分或存档恢复证据。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从开始到结束的流程 + 每个关键节点的潜在流失风险点。

**内容说明**

普通点击开始后再点击，原小鸟出现倾斜飞行姿态、位置较菜单改变，背景与管道场景出现；原分数0。本轮未穿过管道或取得分数。第4步重载。

**内容说明**

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：游戏是否具备“明确目标 → 明确规则 → 达成反馈 → 奖励激励 → 下一目标”的完整闭环。

**内容说明**

目标为操控原小鸟避开碰撞；普通点击触发onJump→原逐帧速度和位置更新→小鸟飞行姿态与场景反馈；碰撞通过原showResult进入结果路径。成功计分与长期激励未在本轮验证。

## 9. 玩法规则

**维度定义**：核心循环、玩法规则、目标与进度。

**内容说明**

src/project.84a05.js:Bird.onJump把旋转设为-45并将velocity设为birdJump；Bird.update在非结束状态逐帧把velocity加到y，再减去gravity，并按速度改变姿态。Bird.onCollisionEnter发送showResult。Constant声明管道与地面滚动参数。本轮只看到飞行、0分和重载，没有成功穿管或新纪录证据。

## 10. 数值配置

**维度定义**：影响玩法的关键数值。

**内容说明**

源码Bird.gravity=0.4、birdJump=6.6、初始velocity=3；Constant.PIPE_SPEED=-6、GROUND_MOVE_INTERVAL=0.01、GROUND_VX=-2。均为源码内部值，不推断像素每秒。原实机分数与最佳均0。
