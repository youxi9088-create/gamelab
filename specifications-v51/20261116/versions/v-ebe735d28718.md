# Slime Laboratory 游戏规格说明书

格式版本：V5.1

仅记录有依据的实现层事实；字段非必填。空白表示代码未披露或未登记，不代表不存在、不可玩或验收通过。

## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：Slime Laboratory

**玩法类型**

平台动作 / 史莱姆实验室

**操作方式**

本轮原1PLAYER按钮、Right1900ms/2200ms移动、Up220ms跳跃。原2PLAYER/Help/Credits/Pause/Sound保留但未测试，不猜双人键位。

**视角与布局**

原侧视像素实验室、镜头跟随角色，右下计时/分数、左侧原绿色量表与暂停/声音按钮。

**画面维度**

2D

**引擎**

原Neutronized/AwayFL AVM运行器和原Flash SWF，浏览器Canvas/WebGL与JavaScript宿主。

**程序语言**

编译后SWF/AVM字节码、可编辑JavaScript/HTML运行器；未恢复原ActionScript工程。

**结论字段**

- `game_summary` = 操纵原绿色史莱姆在实验室平台、坡面和通道移动与跳跃，接触原收集物获得原计分反馈；原1PLAYER/2PLAYER等模式菜单和完整原游戏包保留。

**已验证流程与未覆盖范围**
