# 泡泡2048 游戏规格说明书

规格标准：V5.1

## 1. 基础事实

格式版本：V5.1

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

泡泡2048，原入口标题“泡泡龙2048”。2D正面竖向球场，拖动瞄准并发射数字球，相同数字相碰合成更高数字。Cocos Creator 2.4.8发布运行时，程序语言JavaScript。没有原Cocos编辑器工程或TypeScript源码。依据：原入口、引擎版本、`assets/main/index.88b99.js`。

## 2. 资源类型

**维度定义**：内容元素类别及其引擎资源格式。

**内容说明**

Cocos发布资源包含引擎与物理引擎JS、业务JS、场景/预制体序列化JSON、数字球与背景/UI图片、音频、图标等。resources.loadDir回调40项资产成功，原文件统计见`verification/provenance.json`；不把文件数当成独立美术数量。`engine_asset_system` = Cocos。

## 3. 核心挑战维度

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

主维度为操控：选择发射落点，借助边界反弹；次维度为策略：根据数字和球群位置安排同数字碰撞。`core_challenge_type` = [operation, strategy]。依据：Game.onTouchEnd、Ball.onBeginContact、BallLevelUp。

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

鼠标按住、移动、松开发射数字球，界面按钮点击。原输入使用Cocos TOUCH_START/MOVE/END；只实测鼠标，实体触屏未测。松开时目标相对发射点纵向距离须≥100，横向差不能为0；不满足则不发射。设计尺寸1080×1920，由等比iframe适配。依据：Game.onTouchEnd与host-fit.js。不填写APP适配评价。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

观察球群及待发数字 → 拖动瞄准 → 松开发射 → 碰撞同数字合成/不同数字停留 → 分数和球群变化 → 选择下一个方向。`core_loop` = 观察→瞄准→发射→合成反馈→下一球。依据：Game、Ball与两次真实发射记录。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

启动 → start菜单 → START进入game → 发射合成 → 暂停 → 继续/重新开始/返回主页。源码还包含复活与结算面板，但本轮未触发失败。实测两次发射得分0→16→28，暂停普通重开为0，刷新回start菜单。不填写虚构耗时或流失风险。依据：verification/02-after.json、03-after.json、04-restart.json、05-reload.json。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

同一局通过同数字合成提升球等级，超出当前解锁等级时扩展可随机生成的等级范围。初始unlockArray=[0,1,2,3]，本轮未解锁更高等级；没有确认跨局成长或成绩持久化。依据：Game.BallLevelUp、getRandomIndex与原存储调用。

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：目标、规则、反馈、激励和下一目标。

**内容说明**

**目标**：持续合成更高数字球并提高当局得分。

**规则**：按住拖动后释放数字球；同等级接触后原球回收，创建高一级球并计入该级对应分值；不同等级碰撞保留原球。球触及结束条件时进入复活或结算，结算分支本轮未实测。

**反馈**：数字、球大小/颜色、碰撞位置、缩放/粒子效果和当前分数。原音频保留，听觉未验证。

**激励**：分数与本局更高数字球，后续可解锁球等级；本轮0→16→28。

**下一目标**：根据合成后的球群选下一球落点；暂停中可普通重开，实测28→0。

`loop_completeness` = 部分（发射、合成、计分、暂停和重开通过；失败结算与合成2048未覆盖）。依据：业务Game/Ball模块与5步记录。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

相同BallIndex接触后合成为下一级；合成后curScore增加该级数字值，原球进入对象池。数字数组为2、4、8、16、32、64、128、256、512、1024、2048。源码还定义13/14号特殊球，不据此声称普通生成可获得。发射开始后每2秒检查已接触球是否越过deadLine；首次结束显示复活，再次结束显示结果。广告复活/道具成功回调在本地不会触发。依据：Ball.onBeginContact、Game.BallLevelUp/update。

## 10. 数值配置

**维度定义**：影响玩法的生命、概率、时长、速度和经济等数值。

**内容说明**

| 参数 | 源码或实测值 |
| --- | --- |
| 数字等级表 | 2至2048，共11级 |
| 初始可随机等级 | 索引0—3 |
| 发射水平速度 | ±1500 |
| 重力 | (0,3000) |
| 发射最小纵向差 | 100 |
| 发射间隔门槛 | 0.3秒 |
| 结束检查间隔 | 2秒 |
| 实测计分 | 0→16→28，普通重开0 |

依据：Game脚本及verification。物理数值是引擎内部单位，不转换为现实速度。

## 11. 关卡配置

**维度定义**：关卡布局、目标、数量、递进和难度参数。

**内容说明**

取得一个game球场和start菜单，未发现逐关地图体系。原初始球群包含2、4、8、16，碰撞后球群改变；数字等级数组不能解释成11个关卡。未验证完整难度曲线或全部解锁。依据：Game.init/start、场景配置与实机截图。

## 12. 系统设计

**维度定义**：功能系统及界面流程。

**内容说明**

系统包括物理碰撞、数字合成、对象池、效果池、分数、暂停、普通重开、结果/复活/奖励弹窗。源码UIResult只有有效Token才提交在线成绩，默认Token空；本地不提供账号/排行。读取localStorage仅用于register_time遥测辅助，遥测本地禁用；本轮keys=[]，刷新返回菜单，不宣称有进度续玩或高分保存。依据：Define、AdMgr、UIResult与05-reload.json。

## 13. 主题化包装

**维度定义**：文字、叙事、命名及美术内容。

**内容说明**

热带海岛背景、椰树、云朵和发光彩色数字球；原“泡泡2048”标识、中文暂停按钮、START和UI美术保留。未发现人物剧情/对话，不补写世界观。依据：原图片与screenshots。

## 14. 养成系统 + 经济系统

**维度定义**：成长要素和资源产出、消耗、回收机制。

**内容说明**

可确认的成长是本局合成数字与unlockArray。源码分数阈值[500,2000,3500,5500,8000,10500,13000,16000,20000,25000,30000]可触发广告道具弹窗；本轮未到阈值。本地隐藏广告领取，不发放奖励。未确认货币、付费商店或跨局养成经济。依据：Game.updateGame、UIReward。

## 15. 角色 / 单位设定

**维度定义**：角色单位的数量、属性、能力、定位和关系。

**内容说明**

无人物角色。主要单位为带数字的物理球，等级对应2至2048；特殊道具球索引13/14由源码定义。它们是玩法对象，不填写人物阵容或虚构技能背景。依据：Ball、Game.ballsPrefab与数字数组。

## 16. 商业化

**维度定义**：已实现的广告、内购、订阅、买断和付费点。

**内容说明**

原17yoo MINI_GAME_SDK激励广告用于复活和特殊球，结果页也有周期视频调用；无实测付费流程。本地SDK只回调不可用/失败，不回调成功，隐藏广告专属按钮与在线排行/退出入口。普通暂停、重开、返回菜单保留。原主业务及物理引擎不修改。依据：local-host.js、AdMgr、UIRelive、UIReward、UIResult。
