# Grow Run 3D 游戏规格说明书

规格标准：V5.1

## 1. 基础事实

**维度定义**：让读者第一眼知道“这是什么类型、什么操控体验的游戏”，以及它的技术栈。

**内容说明**

平台名称《Grow Run 3D》，目标历史版本`v-6fd9f0da3b55`。入口`index.html`；代码通过Three.js `WebGLRenderer`渲染三维跑道路段与队伍。此文档为只读源码补写，没有新增试玩或将静态路径当成实机验收。定位：index.html:1040–1051、2467起；源码哈希见配套补写回执。

## 2. 资源类型

**维度定义**：游戏中游戏内容元素的资源类型是什么——即在哪个引擎运行下的资源格式。

**内容说明**

入口HTML同时包含界面、样式和游戏逻辑；依赖本地_remote下的three.module.js与three.core.js；另有local-host.js、runtime-resource-map.js、runtime-resource-bindings.js。运行逻辑维护道路数组T、宽度z、队伍k、飞出成员He、障碍/道具ce和场景I。定位：index.html:1040–1051、2467–2544、3090起；不把源码文件数当成全部可见资源数量。

## 3. 核心挑战维度

**维度定义**：游戏核心玩法主要挑战 / 满足人的什么。

**内容说明**

控制队伍在跑道上前进并保留成员；横向移动、跳跃、招募和躲避障碍影响队伍。代码在游戏进行且队伍k为空时调用Gn结束本局。定位：index.html:3090–3150、3250–3316。

## 4. 操控方式

**维度定义**：操控本身的复杂度 + 需要玩家判断的时机 / 策略复杂度。

**内容说明**

左右方向键或A/D调整横向目标ue，空格设置跳跃请求Ce。鼠标/触摸指针按下记录起点，横向拖动按屏幕宽度换算ue；无明显拖动的松开触发跳跃，jumpBtn也触发跳跃。P/Escape暂停，M切换声音，界面按钮支持暂停/继续和声音设置。定位：index.html:2957–2986、3093–3103。此处为源码支持，不宣称每种输入均已实测。

## 5. 行为路径

**维度定义**：玩家一局里重复做什么。

**内容说明**

start按钮在非结束状态启动：若队伍为空先$t重置，再由Co清零本局计分、设置Q=true并隐藏菜单；循环处理移动/跳跃/碰撞并更新距离、得分、人数和金币；队伍全部离开后Gn设置结束状态并提交当前代码计算的分数给RemixSDK。重开回调执行$t和Co。定位：index.html:2559–2573、2624起、3008–3041、3314–3319。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从开始到结束的流程 + 每个关键节点的潜在流失风险点。

**内容说明**

源码路径为菜单→start/Co→持续前进与横向调整→招募或收集/障碍碰撞与掉落→队伍归零时Gn结束→本地宿主结果面板/重开。原代码的飞出动画将成员移入He而不是保留在队伍k，He成员继续受重力并在远低于道路后清除。定位：index.html:2534–2573、3299–3319；local-host.js:9起。没有据此编造真实通关时间或流失风险。

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：游戏是否具备“明确目标 → 明确规则 → 达成反馈 → 奖励激励 → 下一目标”的完整闭环。

**内容说明**

目标：保留队伍并获得本局分数。规则：方向/拖动改变横向位置，跳跃请求作用于落地成员；招募将成员加入k并增加计分值，碰撞和跌落将成员移出k。反馈：队伍阵形、飞出动作、闪屏、距离/得分/人数/金币界面更新。激励：招募、金币与前进距离进入分数公式，连续招募提高招募计分倍数；结束后与本地最佳分比较并保留更高分，下一轮可重新尝试。定位：index.html:2489–2498、2534–2591、3090–3150、3250–3319。只还原这些代码闭环，没有新试玩结论。

## 9. 玩法规则

**维度定义**：核心循环、玩法规则、目标与进度。

**内容说明**

移动：ue受道路宽度约束，he向ue平滑靠近，各成员在队伍阵形偏移上前进。跳跃：落地成员的jumpT按阵形距离错开，触发后vy=9.5，空中vy按26×dt下降；无可落地道路且高度继续降低时调用Cn掉落。障碍碰撞按纵向、横向和高度范围判断，kn把成员移入飞出列表并清零连击；收集招募对象可把成员加入队伍。游戏进行且k.length===0时结束。定位：index.html:2489–2544、2575–2591、3090–3152、3250–3316。静态规则存在不代表全部障碍和地图均已验证。

## 10. 数值配置

**维度定义**：影响玩法的关键数值。

**内容说明**

源码计分：go=10×lt+2×_e+floor(max(0,v-_t)/10)。lt是累计招募计分值，招募时按dt()增加；dt()=min(5,1+floor(me/5))，me为连续招募计数，受碰撞/掉落清零。方向键横向目标变化率为12×dt；指针横移换算系数22，显著拖动阈值0.35；跳跃vy=9.5、重力项26×dt。以上均为该版本内部变量/源码配置，不推断为现实单位或实测难度。定位：index.html:2483–2497、2957–2974、3093–3138。

## 12. 系统设计

**维度定义**：功能系统清单、UI 流程。

**内容说明**

游戏HTML维护队伍、道路、障碍、计分、碰撞和本地最佳分；local-host.js是交付中的离线Remix宿主，保存本地游戏状态并呈现结果面板，不是原远端账号或联机服务。Gn尝试调用RemixSDK.singlePlayer.actions.gameOver，宿主接收游戏自行计算的score。存档：crowdrun-best2用于更高分；crowdrun-sound、crowdrun-qual分别保存声音和画质偏好。定位：index.html:2440–2478、2559–2573、2987–3006；local-host.js:1–14及其状态保存逻辑。未新增验证跨设备/账户保存。

**维度定义**：有哪些角色/单位、各自定位（玩法层面）。
