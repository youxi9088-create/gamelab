# 消除数字块 游戏规格说明书

规格标准：V5.1

## 1. 基础事实

格式版本：V5.1

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

**既有内容**：来源名称「消除数字块」，原运行包名称 Bombs Drops - Physics balls。玩法为弹球射击与数字几何块消除；从顶部发射弹球，观察反弹和数字变化，避免不断上升的方块抵达发射端。采用2D正面固定球场和鼠标拖动/松开操作。

引擎为 Construct 2 HTML5 导出运行时，程序为 JavaScript，事件模型与资源声明保存在 `data.js` 的JSON中。没有取得原 `.capx` 编辑器项目。

`game_summary` = 2D弹球击打数字块游戏。

依据：原 `index.html`、`c2runtime.js`、`data.js`；实机 `screenshots/03-game-start.jpg`、`05-game-over.jpg`。

## 2. 资源类型

**维度定义**：内容元素类别及其引擎资源格式。

**内容说明**

**既有内容**：采用Construct 2构建资源体系，含引擎JS、JSON事件模型、精灵图集、音频、网页字体和JSON/CSV配置。保留259个图片文件（包括图集、游戏对象、界面及SDK图标），不将文件数等同独立美术内容数量。音频为47个原版OGG；原站47个备用M4A链接均404，本地由相同OGG转码补齐AAC/M4A，原OGG字节未改动。

原字体实际可取得的 `notosans-regular-webfont.woff2` 保留；原站不存在的备用WOFF/TTF和未被语言配置引用的JP字体链接从CSS中移除。场景与对象配置位于 `data.js`；界面显示语言字词位于 `langlibrary.json`，星级阈值位于原 `starsunlocked.csv`。

`engine_asset_system` = Construct 2 HTML5。

依据：`verification/provenance.json`、`verification/audio-derivatives.json`、`font.css`、`data.js`。

## 3. 核心挑战维度

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

**既有内容**：主维度为操作/操控：选择发射方向，利用物理碰撞与反弹击打数字块。次维度为策略与挑战：选择优先处理的位置，处理每轮上升的几何块。

`core_challenge_type` = `[operation, strategy, challenge]`。

依据：`data.js` 的 GameMain 事件、弹球与块对象配置；`verification/normal-shots.json` 的真实发射、分数与步骤变化。

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

**既有内容**：鼠标按住球场内的发射位置，拖动瞄准方向，松开发射；界面使用点击。源码存在触摸输入插件；本轮使用鼠标，实体触屏未验证。

| 动作 | 作用 |
| --- | --- |
| 主菜单点击播放 | 进入球样式商店 |
| 商店点击播放 | 使用当前球进入对局 |
| 按住、拖动、松开 | 瞄准并发射；等待本轮弹球运动结束 |
| 点击暂停 | 打开对局暂停界面 |
| 点击底部道具 | 使用已有库存；已实测冻结道具库存2→1 |
| 结算点击重玩 | 返回商店，再点击播放开新局 |

APP适配结论和手速评级不填写。390×844竖屏布局已查看，触屏手感未验证。

依据：`data.js` 输入事件；实机截图与 `verification/consumable-used.json`。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

**既有内容**：观察方块数字与位置 → 选发射方向 → 发射并观察反弹 → 命中改变数字、消除并计分 → 本轮结束，方块上升和补充 → 再次选择方向。

`core_loop` = 观察→瞄准发射→反弹击打→数字与分数反馈→下一步。

依据：`data.js`、`verification/normal-shots.json`。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

**既有内容**：启动加载原资源与本地存档 → Splash主菜单 → Shop球样式选择 → GameMain对局 → GameOver结算 → 返回主页或经Shop重玩。暂停与设置作为界面分支保留。

本轮实际从初始0分打至18分，在步骤6进入结束页；重玩返回Shop，再开始时Score=0、步骤=1。没有采集流失数据，不填写流失风险或虚构节点耗时。

依据：原项目布局与 `verification/final-settlement.json`、`normal-shots.json`；`screenshots/05-game-over.jpg`、`06-normal-replay.jpg`。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

**既有内容**：同一局的步骤推进伴随方块补充与上升，分数记录写入本地存档；钻石与球样式商店提供跨局数据。原 `levelconfig.json` 有40条空记录，星级CSV有400条配置记录，不能据此声称已实现或开放了40/400个可玩关卡。实测布局走Splash→Shop→GameMain，配置中的关卡选择被跳过。

`progression_loop` = 有（步骤推进、分数记录与球样式数据）；未实测高价球购买或完整星级成长。

依据：`data.js` 的步骤/存储事件与SKIP_LEVELSELECT配置、`shop.json`、`levelconfig.json`、`starsunlocked.csv`。

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：目标、规则、反馈、激励和下一目标。

**内容说明**

**既有内容**：

- **目标**：击打数字块，延长当前局并获得分数；结束后可再次挑战。
- **规则**：从顶部发射弹球，弹球与数字块碰撞，方块数字随命中变化。每轮结束后进入下一步骤，剩余几何块向发射端推进；达到结束条件时显示游戏结束并结算。
- **反馈**：弹球轨迹与反弹、方块数字、消除效果、分数、步骤与结果面板。原音频保留，听觉未独立验证。
- **激励**：本地分数记录、钻石和球样式库存。普通对局不依赖广告；不伪造广告奖励或在线成绩。
- **闭环**：瞄准与击打 → 数字改变和分数反馈 → 下一步骤的新局面 → 结束结算 → 返回Shop选择球并重玩。

`loop_completeness` = 完整（基本计分、失败、结算、返回与重玩实测；商店购买和星级成长未穷尽）。

实机证据：0→3→7→10→18分，步骤6结束，统计击碎3块；新局归0分/步骤1，冻结道具2→1，刷新后存档score仍18、道具仍1。

依据：`verification/normal-shots.json`、`final-settlement.json`、`consumable-used.json`、`final-save.json`。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**既有内容**：按住、拖动并松开以发射弹球，利用反弹击打带数字的圆形、三角形与四边形。命中改变数字，几何块消失与分数变化按原事件表处理。本轮数字块、物理反弹、计分、步骤推进和失败结算均实际运行。

已有库存的冻结、加球与闪电道具保留；本轮只实际使用冻结。原广告获得额外资源、在线排行榜与推广服务不在本地提供。几何块推进到发射端附近后触发结束；精确碰撞边界与全部特殊球计分公式没有逐分支核对，不补造阈值。

`playability` = 可玩（18分结束、返回与重玩已实测）。

依据：`data.js` 的事件数据与对象配置；真实状态记录见verification。

## 11. 关卡配置

**维度定义**：关卡布局、目标、数量、递进和难度参数。

**内容说明**

**既有内容**：运行时声明7个布局：Splash、LevelSelect、GameMain、GameOver、tuto、Shop、Instantiator；它们是场景/界面布局，不是7个可玩关卡。本轮进入的是逐步补充、向上推进的GameMain球场。重开时初始几何块类型和数字可变化。

原关卡JSON含40条空对象，星级CSV含lvl_1至lvl_400的400条记录。数据文件数量与可进入关卡数量分开记录；本轮未验证关卡选择或全部星级阈值，也不推测难度曲线。

`monetization` = 原版广告接口；本地不提供广告变现或在线账户。

依据：`index.html`、`js/networks/*`、`externalsettings.json`；适配为`local-host.js`、`cocooncaller.js`和本地排行榜桥。
