# 玩梗大作战 游戏规格说明书

规格标准：V5.1

## 1. 基础事实

格式版本：V5.1

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

《玩梗大作战》，4k99详情924/category4，Cocos Creator2.4.8，1080×1920竖屏原发布包，无编辑器工程。

## 2. 资源类型

**维度定义**：内容元素类别及其引擎资源格式。

**内容说明**

原文字方阵题库、字体、模式菜单、人物插画、计时/提示/加时UI及音频；resources59、audio17项loadDir采集。

## 3. 核心挑战维度

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

**核心体验**

接化发三字绿色高亮，game1.count从0到1，60秒开始倒计时；未听测音频。

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

点击消消乐与中二关卡；按住连续滑过接→化→发后松手完成词组，不能逐字独立点击代替滑动。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

模式菜单→消消乐→中二→滑动接化发→成功1/11→刷新回模式菜单。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**
