## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：Chess Pro

**玩法类型**

棋类

**操作方式**

点击机器人头像 → 选择对手 → 开局配置中。
点击执子颜色 → 选白、黑或随机 → 开局前。
点击开局选项 → 选标准或随机布阵 → 开局前。
点击挑战按钮 → 开始人机对局 → 配置完成后。
点击好友图标、开始对局 → 同机双人对弈 → 模式设置中。
依次点击己方棋子与目标格 → 尝试走子 → 轮到该方时。
点击翻转 → 切换棋盘朝向 → 棋局中。
点击撤销 → 回退走子 → 满足原模式条件时。
点击认输或和棋 → 打开相应确认 → 棋局中。
点击复盘 → 查看原生分析 → 对局结束后。
点击本地领取 → 确认当前可领取项目 → 领取提示中。

正面俯视的8×8棋盘，中间展示棋子与坐标，右侧为配置、走子记录或复盘面板，左侧为模式导航。棋盘可翻转；同机模式另有每步后自动旋转选项。

**画面维度**

2D

**引擎**

原生 Web；内嵌国际象棋规则与分析引擎，机器人计算使用 Web Worker，并保留同步后备。

**程序语言**

JavaScript（页面、规则与 AI）；HTML/CSS（界面）。原作者工程语言未另行确认。

- `game_summary` = 2D 俯视国际象棋：合法落子、机器人或同机对弈，并带战术谜题、每日题和复盘。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

**核心玩法**

离线国际象棋。可与10名不同强度的本地机器人对弈，或两人在同一设备轮流走棋；保留战术谜题、按日期选择的每日谜题、对局复盘、成就和外观。玩家依合法走法移动棋子，以将死对方王为对局目标。在线匹配、邀请房间、云端排行榜和平台广告已退役。

**结论字段**

- `core_loop` = 观察局面与轮次 → 选择己方棋子 → 选择目标格 → 检查合法性并落子 → 对手回应 → 更新棋谱/将军/终局 → 继续判断。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

**游戏流程**

开始：选择机器人或同机对局，设置执子方、标准/随机布阵及适用的时钟。
操作：选择棋子和目标格，规则引擎拒绝非法走法；机器人自动计算回应，同机模式由另一方轮流操作。
结果：将死、和棋或认输等规则结束棋局，显示结果、原因和棋谱；本轮实际为黑方将死。
继续：可再下一局、返回配置或复盘；复盘可逐步回看局面。未结束的棋局可存档并在刷新后恢复。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

**奖励与成长**

机器人进度每名最多3颗星，分别记录获胜、执黑获胜、满足原“干净对局”条件；10名合计最多30颗机器人进度星。成就与连续游玩记录另按原奖励表贡献星数，星数用于符合条件的棋子外观。原免费外观和原奖励数值不变。原广告可选项目改为主动本地领取；取消不解锁、不撤销、不增加谜题额度。谜题基础每日5道，确认领取后每次增加5道的原额度规则保留。实测同机将死触发“良师益友”成就，复盘取消仍锁定、确认才可进入；未验证所有成就、外观或机器人星级解锁。

**结论字段**

- `progression_loop` = 对弈/题目 → 按原条件记录进度与成就 → 解锁适用外观或继续挑战 → 再次对弈/题目。

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：目标、规则、反馈、激励和下一目标。

**内容说明**

**目标规则反馈激励闭环**

短期目标：完成当前合法落子、回应威胁；战术题按原题目线路求解。中期目标：结束一局对弈或完成当前题目。长期记录：机器人进度星、成就、连续游玩和外观。
规则：8×8棋盘、轮流行动；非法走法拒绝，按原引擎判定将死/和棋等终局；机器人由原配置计算回应。
反馈：选中与合法目标、棋盘变化、棋谱、行棋方、将军/终局文字；复盘展示准确率与走子分类。音效合成存在于代码，本轮未作听觉验收；触觉反馈未确认。
激励：对局记录及满足条件的机器人进度星/成就；谜题原额度和外观原解锁条件保留。可选本地领取需玩家确认，取消不发放。
下一目标：再下一局、切换机器人、继续战术题/每日题或查看复盘。实测同机短局将死→结果→复盘/再开局；其余完整目标未穷尽验证。

**目标机制**

源码原引擎status与题库控制器：棋局将死对方王，谜题寻找原给定获胜线路；本轮达成的是同机将死，非所有机器人或题库完成。

**玩法达成机制**

源码原规则与棋局控制器：选择棋子→规则检查目标→合法落子→对方回应→将死/其他原终局；个人成就按原触发条件记录。实际非法步拒绝和Qh4#结束证明这条棋局链路。

**反馈机制**

源码棋盘/棋谱/复盘渲染：显示轮次、选中与合法目标、棋谱、将军/终局、复盘准确率和走子分类；本轮画面与结果已打开截图核对，声音仅代码保留未作听觉结论。

**驱动力机制**

源码le/ee/V：机器人进度星、个人成就、连续游玩与外观解锁形成可见进展，谜题评分与每日个人记录提供重复挑战；不再使用云排行榜。

**延续机制**

源码模式导航、重开、题库与机器人进度：结束后再开一局、切换对手、选择其他谜题或按日期挑战；实际重开与模式切换成立，未穷尽题库。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**目标、规则与结算数值**

目标：遵守国际象棋走法并将死对方王。非法走法不改变棋盘与轮次；实测兵从初始格跳三格被拒绝。
结束：原引擎包含将死、无合法走法且未被将军的逼和、子力不足、50回合规则（100个半回合）和三次重复；另保留认输、同意和棋及所选时钟超时。除将死外，其余结束条件本轮仅源码确认。
对局结果使用1-0、0-1或1/2-1/2；本轮普通点击1.f3 e5 2.g4 Qh4#，原结算为黑方获胜、将死。机器人标称强度为配置标签，不是玩家本轮得分。
每日谜题源码计分：令t=耗时秒数+10×错误次数；t≥600时为0，否则为round(1000×2^(-t/90)×(1-(t/600)^6))，本轮未实际完成每日题。复盘实测白方47%、黑方100%，该百分比是原引擎对此局的分析，不是通用奖励公式。

**已验证流程与未覆盖范围**

实机已验证：最终包启动与棋子渲染、非法走子拒绝、同机完整将死/棋谱/成就/再开局、复盘领取取消与确认、原生复盘47%/100%、同机e4刷新恢复、Pebble400回应d5及e4/d5刷新恢复。最终网络窗口111事件/57请求完整无截断、无外联、无失败、无HTTP错误和脚本异常，控制台警告错误为空。
源码/材料确认：10机器人、1,300谜题、10棋盘、7棋子套装、33成就、原难度与奖励表、原引擎逐字节摘要一致及核心控制器语义摘要一致。
未覆盖：其余机器人完整胜局、全部题目/每日、所有特殊棋步和和棋路径、全部外观/成就/额度、触屏和听觉。不能将材料齐备或源码存在表述为全部玩法验收。

**内容说明**

**内容规模**

固定内容（源码核对）：10名机器人，标称强度400、600、800、1000、1200、1400、1600、1800、2000、2200；1,300道内置战术谜题，原标称评分400—2813；10种棋盘配色、7套棋子、33项成就。

**结论字段**

## 12. 系统设计

**维度定义**：功能系统及界面流程。

**内容说明**

**玩法系统与相互作用**

棋盘/规则引擎：维护棋子、行棋方、合法走法、将军和终局。
机器人/计算工作器：读取原难度、开局库和当前局面，返回合法回应；工作器不可用时保留原同步计算后备。
同机控制器：双方共用棋盘、轮次与适用时钟；原在线收发和远端落子已退役。
谜题/每日：题库提供初始局面、演示步和目标线路；正确/错误反馈影响原题目状态及适用记录。
复盘：分析原棋谱并展示准确率、走子分类和回放。
进度/钱包/成就：按原触发与奖励表记录个人成长，不伪造服务器排名。
本地领取：独立确认/取消提示，只在确认后进入原可选奖励分支。
渲染与存储：内嵌原字体、SVG棋子、本地音效合成及个人存档，运行不需要平台SDK。

**界面流程与反馈**

左侧导航保留机器人、同机好友、谜题、每日、成就、主题和设置；在线对战按钮、邀请按钮不再出现。开局面板提供对手、颜色、布阵及适用时钟。棋局右侧显示行棋方、棋谱、翻转/撤销及结束操作。终局弹窗显示胜负、结束原因、复盘和再下一局。复盘页显示双方准确率、走子分类、逐步回看和返回。领取提示明确“本地领取”，显示确认与取消；取消有未解锁反馈。本轮1280×720截图中棋盘、按钮和结果可见，无阻断遮挡；未作全设备布局验证。

**存档方式**

使用浏览器本地存储gambit-chess-v1，保留原设置、机器人进度、成就、外观解锁、谜题/每日记录、连续游玩及未结束棋局。原保存逻辑在落子、完成和设置变化等节点触发。实测同机走出e4后刷新并回到同机页，棋谱e4与黑方走棋恢复；机器人e4/d5刷新后恢复原局面。已结束棋局不作为进行中存档恢复；复盘结果等临时对象不保证跨刷新保留。不提供云同步，清理浏览器数据会丢失个人记录。
