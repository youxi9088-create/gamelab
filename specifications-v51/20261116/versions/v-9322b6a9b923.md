# EVO.io 游戏规格说明书

格式版本：V5.1

仅记录有依据的实现层事实；字段非必填。空白表示代码未披露或未登记，不代表不存在、不可玩或验收通过。

## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：EVO.io

**玩法类型**

浏览器端 .io 竞技生存页游（本地离线运行包）

**操作方式**

1. W/A/S/D 或方向键 → 四向移动 → 键盘持续按下（实机验证）
2. Space → 冲刺(BOOST) → 按下触发，冲刺效果与消耗条件未单独量化验证
3. 自动攻击 → 进入射程自动射击/挥砍 → 无需按键，触发范围未精确验证
4. 手柄映射（L/✚移动、R瞄准、A/RT冲刺） → 仅界面图例提示，未连接手柄验证

**视角与布局**

俯视/顶视角（Top-down），实机已验证游戏内画面与小地图

**画面维度**

2D

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

**核心玩法**

无尽单人生存：玩家控制角色在开放场景中移动、冲刺、自动攻击敌人并收集资源，以提升等级和分数，刷新个人最佳成绩。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

**游戏流程**

开始：加载后显示主菜单、排行榜与操作提示；操作：点击SOLO进入无尽模式，使用键盘移动与冲刺，自动攻击收集资源；结果：死亡后显示KNOCKED OUT/RESPAWNING并记录BEST分数；继续：返回菜单可重开，刷新后BEST分数自动恢复。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

**奖励与成长**

短期：单局内通过击败敌人/收集资源提升等级与分数；长期：刷新个人最佳BEST分。无角色永久升级、装备或剧情进度的实机证据。

## 8. 核心闭环（目标-规则-反馈-激励）

**内容说明**

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**目标、规则与结算数值**

目标：在无尽单人生存中获得尽可能高的分数。成功/失败：失败条件为生命值归零（KNOCKED OUT），随后自动复活继续；得分公式未确认。已查证：刷新后BEST 32恢复。

**已验证流程与未覆盖范围**

实机验证：页面启动、菜单、SOLO进入、移动、升级、死亡/复活、分数变化、本地保存与刷新恢复、排行榜与HUD。未验证：手柄输入、在线多人、精确攻击范围与冲刺数值、全部敌人类型与地图边界。

## 11. 关卡配置

**维度定义**：关卡布局、目标、数量、递进和难度参数。

**内容说明**

**内容规模**

固定内容：标题、主菜单、排行榜、操作说明图例、角色与敌人外观、六边形地图；单局内资源与敌人生成逻辑为程序生成，具体规则未完全验证。

**场景、关卡与难度设计**

无尽开放场景，六边形网格背景，散布可收集光球与敌人；地图边界与具体生成规则未验证。

## 12. 系统设计

**维度定义**：功能系统及界面流程。

**内容说明**

**玩法系统与相互作用**

对象：玩家角色、敌人/资源、排行榜条目；状态：等级、生命值、经验值、分数、位置、冲刺；触发：移动输入更新位置、Space触发冲刺、自动攻击/收集进入范围的目标、死亡后触发RESPAWNING；系统交互：输入→移动/冲刺→战斗/收集→计分→排行榜/本地保存。具体数值未确认。

**界面流程与反馈**

主界面（H1 EVO.io）→ 排行榜列表 → 操作图例 → 按钮SOLO/PLAY ONLINE；游戏内：HUD（左上角MENU、右上角排行榜、左下角等级/经验、中央升级与复活提示）；死亡后自动复活并继续游戏，返回菜单显示BEST。

**存档方式**

保存内容：个人最佳分数（best），格式{v:1,best:N}；保存触发：死亡/单局结束时调用saveGameState；恢复方式：启动时从initialGameState读取并设置BEST；不保存项：在线账户、多人对战数据、未完成的单局进度。
