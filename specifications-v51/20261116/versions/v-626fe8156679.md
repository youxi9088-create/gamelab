Tab → 回放录像
鼠标左键 → 锁定指针/交互

**视角与布局**

第一人称身体摄像机视角，带录像机 UI 叠加（REC、电量、LTE、时间戳、坐标）

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

**核心玩法**

玩家在雨夜废弃疗养院中搜索失踪者 Daniel，通过无线电与同伴 MARA 联系，依靠手电筒/红外夜视探索，开门、躲藏、收集道具、启动发电机、乘坐电梯，并躲避会模仿声音的怪物。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

**游戏流程**

开始：标题菜单选择单人开始 → 亮度校准 → 无线电剧情触发 → 操作：探索疗养院、与对象交互、推进目标 → 结果：触发剧情/获得道具/被怪物抓住/到达出口 → 继续：返回检查点或返回标题。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

**奖励与成长**

以目标提示推进：进入疗养院 → 查看访客日志 → 寻找 Daniel 线索 → 启动发电机 → 获取钥匙卡 → 乘电梯到 B1 → 到达出口；部分道具拾取会改变世界状态。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**目标、规则与结算数值**

目标：根据 MARA 无线电提示找到 Daniel 并逃离；成功条件为到达出口触发结局，失败条件为被怪物抓住或伙伴被带走；怪物会被声音吸引，奔跑、开门、碰撞均产生噪声；电池限制手电筒与红外使用时间，氧气限制屏息时间。

**已验证流程与未覆盖范围**

实机验证：标题加载、亮度保存、无线电剧情、WASD 移动、鼠标视角、手电筒、门交互、室内场景渲染、刷新恢复标题；源码确认：关卡结构、控制映射、交互与门逻辑、怪物与网络系统；未验证：完整通关、多人合作、结局动画、怪物直接遭遇。

## 11. 关卡配置

**维度定义**：关卡布局、目标、数量、递进和难度参数。

**内容说明**

**内容规模**

固定关卡：两层结构（GROUND 与 B1），包含大厅、接待处、东走廊、病房、手术室、员工办公室、西翼、发电机室、电梯、楼梯井、礼拜堂、停尸房、锅炉房、维护隧道等；剧情通过无线电语音与字幕推进。

**场景、关卡与难度设计**

关卡由房间矩形与连接边构成，GROUND 层为地面主楼与户外庭院，B1 层为地下室维护区；门、窗、电梯连接不同空间，部分区域需先启动发电机才能通电使用电梯；包含可躲藏点（柜子、床、抽屉）与可拾取道具。

## 12. 系统设计

**维度定义**：功能系统及界面流程。

**内容说明**

**玩法系统与相互作用**

移动系统：WASD+冲刺+蹲伏+探头，含碰撞与脚步声；光照系统：手电筒/红外/场景点光源，含闪烁与电量；交互系统：射线检测目标，门可快开或慢开，柜子/床可躲藏；音频系统：3D 脚步声、门声、风声、雨声、无线电语音、怪物音效；怪物系统：模仿人声、根据视线与噪声追击；网络系统（可选）：WebRTC P2P 合作同步玩家与怪物状态。

**界面流程与反馈**

标题菜单（开始/合作/画质）→ 亮度校准 → 无线电剧情界面（任务目标 + 操作提示 + STOP 按钮）→ 正式玩法 HUD（REC、电量、信号、时间、坐标）→ 交互提示 → 字幕 → 死亡/结束界面 → 返回标题。

**存档方式**

仅 localStorage 保存亮度设置（lt_bright）；未发现关卡进度存档。刷新后返回标题菜单，需重新开始；游戏源码中 checkpoint 机制仅在运行时内存中恢复。
