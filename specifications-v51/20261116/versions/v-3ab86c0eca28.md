# 不服来通关 游戏规格说明书

格式版本：V5.1

仅记录有依据的实现层事实；字段非必填。空白表示代码未披露或未登记，不代表不存在、不可玩或验收通过。

## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：不服来通关

**玩法类型**

射击

**操作方式**

鼠标按住拖动或触屏左右滑动移动；点击强化卡片顶部选择；操作原版大厅、武器详情和战斗入口。本地奖励有明确取消与领取按钮。

**视角与布局**

竖屏正面战场，底部玩家横向移动，顶部和中部为沿路径移动的怪物。

**画面维度**

2D

**引擎**

Cocos Creator 3.8.6，沿用原版JavaScript和对应Cocos插件缓存。

**程序语言**

编译后的原版JavaScript可编辑；浏览器适配JavaScript，转换器Python/Node。原作者TypeScript完整工程未恢复。

**结论字段**

- `game_summary` = 移动心形角色自动攻击病毒怪物，选择武器和属性强化，完成主线后领取奖励并养成武器。

## 2. 资源类型

**维度定义**：内容元素类别及其引擎资源格式。

**内容说明**

**内容元素资源类型**

原版PNG/JPEG贴图、Spine骨骼及图集、Cocos序列化场景/预制体、字体、MP3、CCON分块和JSON配置。

**结论字段**

- `engine_asset_system` = 267张原配置表、330条正常主线和320条A/B版本配置本地保留；650条配置引用对应216份地图，未把A/B分支累计为650关。原PNG经去重和无损WebP编码，使用的3432张转换图逐张核对RGBA像素、尺寸和透明通道。原始材料独立归档。

## 3. 核心挑战维度

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

**核心挑战内容**

移动位置、攻击覆盖、武器组合及强化取舍；战斗按原版地图、怪物配置、伤害、冷却与进度规则运行。

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

**操作方式**

鼠标按住拖动或触屏左右滑动移动；点击强化卡片顶部选择；操作原版大厅、武器详情和战斗入口。本地奖励有明确取消与领取按钮。

**操控构成要素**

横向拖动、三选一强化、免费刷新、受次数限制的本地奖励刷新、宝箱确认、结算领取与原版养成引导。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

**核心玩法**

左右移动，自动向上攻击；击败沿路径行进的怪物推进进度，选择强化或武器，处理原版宝箱与奖励，结算后继续养成和下一关。

**结论字段**

- `core_loop` = 移动攻击 → 击败怪物并推进进度 → 选择强化/武器与宝箱奖励 → 原版胜利结算 → 领取金币和武器材料 → 大厅养成 → 下一关。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

**游戏流程**

新玩家沿原版入口进入第1关社牛病毒；原程序显示强化与刷新引导，战斗中选择武器及属性。进度100%出现胜利和奖励，确认后回到大厅，解锁第2关流氓感病毒及武器引导。最终包实际核对第二关进入、移动、攻击、强化、本地刷新取消/领取。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

**奖励与成长**

原版关卡进度、武器和背包模型保留；首次胜利后大厅进入第2关，药丸按原引导从Lv1升至Lv2。其余养成分支未逐一试玩。

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：目标、规则、反馈、激励和下一目标。

**内容说明**

**目标规则反馈激励闭环**

目标是通过当前主线关卡。玩家横向移动并利用自动攻击，击败怪物后通过强化选择改善攻击能力。弹道、命中数字、骨骼动画、卡片选中和进度提供即时反馈。胜利展示原结算并给予金币与武器材料；进入大厅后保留进度，可按原引导养成，再挑战新的怪物与地图。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**目标、规则与结算数值**

保留原版攻击、碰撞、怪物路径、强化、武器和胜负规则。14个战斗/碰撞/升级/奖励核心模块与原包字节相同。没有注入胜利、改动难度或补发测试资源。失败与全部复活边界未专门触发。

**已验证流程与未覆盖范围**

首关胜利、原奖励和首次武器升级在开发工作副本实际观察；最终服务包重新验证全新首关、原样合法进度恢复、第二关移动/攻击/强化和本地领取取消/重复点击。14个核心模块与原版一致。最终两个窗口共1671条请求和1671条响应，无截断、页面/控制台错误、外联或WebSocket；这不代表全部菜单和后续关卡已试玩。52所有18934项运行文件磁盘摘要与清单相符，279项HTTP资源及完整玩家ZIP实校。两端18932项运行文件字节相同，2项仅清单顺序/审查说明差异。

**维度定义**：功能系统及界面流程。

**内容说明**

**玩法系统与相互作用**

**界面流程与反馈**

保留原医疗题材大厅、怪物预览、心形玩家、强化卡片、武器详情、结算及动画。隐藏已识别的营销与在线入口；原广告奖励改为明确本地领取，不展示真实广告。服务页与游戏画面证据分开记录。

**存档方式**

gamelab-bufu63:player-data命名空间，一次localStorage写入保存原模块快照，写入成功后才清理脏状态。实际领取首关奖励与武器引导后刷新恢复第2关、100金币和战力。没有复制微信用户存档。最终包第二关复验使用Agent实际首关取得的原样存档，未编辑字段。
