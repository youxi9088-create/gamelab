# 全民找汉字 游戏规格说明书

格式版本：V5.1

**内容说明**

## 2. 资源类型

**维度定义**：内容元素类别及其引擎资源格式。

**内容说明**

## 3. 核心挑战维度

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

**核心体验**

选择上横后该原笔画变黑；普通提交自然把一及拼音yi填入首个田字格，选择笔画恢复灰态；最后刷新回原首页0/60。

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

普通点击字的独立笔画选中，再普通点击提交；原判断完成后重置笔画。末次刷新。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

5项检查：首次原克字拆笔画题/找出15个常见字；普通点克的上横笔画，原笔画变黑；普通提交，原首格出现一和拼音yi；普通点另一竖笔画；刷新回原全民找找字首页，开始游戏0/60。
