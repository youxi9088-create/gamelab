## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

**玩法类型**

沙盒/合成/解谜

**操作方式**

鼠标左键拖动 → 用当前选中元素绘制 → 需先点击左侧元素按钮选择；鼠标右键拖动 → 擦除画布内容 → 无需预条件；滚轮 → 调整笔刷大小1-9 → 悬停画布；M键 → 静音开关 → 任意时刻；点击元素按钮 → 选择绘制元素 → 按钮位于左栏；点击符文 → 收集符文字母 → 需绘制接近符文位置；riddle输入框+Solve → 提交字母排列答案 → 需集齐6个符文；MOD WORKSHOP按钮 → 打开生物工坊 → 实机验证；GENERATE → 本地随机生成新生物预览 → 实机验证；ADD AS CREATURE → 将预览生物加入元素栏 → 实机验证

**视角与布局**

俯视平面画布，左侧元素工具栏，中央像素沙盒画布，右侧信息面板

**画面维度**

2D

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：目标、规则、反馈、激励和下一目标。

**内容说明**

**目标机制**

短期目标：混合元素解锁新发现；长期目标：集齐6符文解谜解锁aether、完成98项图鉴（依据：main.js riddle与discover逻辑）

**玩法达成机制**

操作：绘制新组合→规则：首次生成判定为发现→目标：累积发现达成成就阈值弹toast并保存（依据：main.js evaluateAchievements/unlockAchievement）

**反馈机制**

绘制即时像素反馈、反应生成新元素、toast提示新发现/成就/符文进度、右栏配方与发现列表实时更新（依据：实机截图与main.js showToast）

**驱动力机制**

98项发现图鉴收集与成就解锁驱动反复实验新组合（依据：main.js achievementDefs与发现计数）

**延续机制**

每次新发现提示剩余可探索组合，符文进度提示下一步搜索方向（推断：依据UI文案与发现计数设计）

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**目标、规则与结算数值**

目标：尽可能多地发现物质并完成图鉴与成就；失败：无失败状态，自由沙盒；隐藏目标：集齐6符文按正确顺序排列字母（答案AETHER）解锁隐藏元素；计分：以发现数量与成就数计

**已验证流程与未覆盖范围**

实机验证：启动加载、元素选择绘制、反应生成、发现记录、符文提示显示、工坊生成与添加生物、CLEAR、刷新后存档恢复；仅源码确认：完整98种发现与全部成就条件；未验证：集齐6符文后的完整解谜流程、全部配方穷举

## 11. 关卡配置

**维度定义**：关卡布局、目标、数量、递进和难度参数。

**内容说明**

**内容规模**

98种可发现物质/生物（源码发现计数98），16条以上显式配方提示，6个隐藏符文，生物工坊可本地生成新生物；固定配方非程序生成关卡

**场景、关卡与难度设计**

单张固定沙盒画布，两侧布置石质遗迹结构藏符文；无关卡制，无程序生成地形

## 12. 系统设计

**维度定义**：功能系统及界面流程。

**内容说明**

**玩法系统与相互作用**

元素系统：固态/液态/气体/生物像素按规则下落与交互；反应系统：两种元素接触按配方表转换为新元素；发现系统：首次生成记录到图鉴；成就系统：按发现进度解锁；符文系统：画布遗迹藏6字母，集齐后可解谜；工坊系统：本地随机组合生成新生物定义加入元素栏

**界面流程与反馈**

主界面：左元素栏+中央画布+右发现/谜题面板；MOD WORKSHOP弹窗：生成预览、ADD AS CREATURE、关闭；FIELD GUIDE：图鉴手册；OPTIONS：设置与说明；toast浮条反馈发现与成就

**存档方式**

localStorage保存pixelSandboxDiscoveries与pixelSandboxAchievements；发现与成就解锁时即时写入；刷新后进度恢复已实机核对一致；画布绘制内容不保存
