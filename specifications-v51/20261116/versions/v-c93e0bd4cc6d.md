# Craig's Castle 游戏规格说明书

格式版本：V5.1

仅记录有依据的实现层事实；字段非必填。空白表示代码未披露或未登记，不代表不存在、不可玩或验收通过。

## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：Craig's Castle

**玩法类型**

平台跳跃 / 城堡攀登

**操作方式**

A/D或←/→移动、Space跳跃（长按影响高度）、Shift冲刺、R重试、Escape暂停；源码支持手柄LS/DPad/A/X/RB/Y。本轮实际Right两次和Space一次，其他未测。

**视角与布局**

固定侧面正交视角；3D几何按2D平面平台规则移动，原死亡/回放镜头保留。

**画面维度**

3D

**引擎**

原Three.js 0.185.1与@remix-gg/three0.22本地引擎；SDK等待/消息桥退役，内部真实localSession替代。

**程序语言**

JavaScript ES模块、HTML/CSS

**结论字段**

- `game_summary` = 控制举着微光的小骑士，在城堡平台、墙面、锯片和熔岩之间跳跃上攀，抵达原关卡灯笼门。失败尝试保留为回放轨迹，胜利按原时间阈值获得星级。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**目标、规则与结算数值**

原22关、固定平台/危险区、移动/跳跃/冲刺/墙跳、死亡计数/回放、原时间阈值算1至3星；原物理和几何不改。

**已验证流程与未覆盖范围**

严格5步：原首关启动、Right按住400ms实际从起点移到平台右侧、Space按住200ms实际离地、Right按住1000ms走出平台/原死亡碎片并显示ATTEMPT02，随后仅观察自动重生至MOVE TO BEGIN；第5步刷新回首关00.00。原22关、几何/物理/碰撞/墙跳/锯片/熔岩/星级/计时/全部112函数语义保留（仅内部platform属性改名localSession及精确素材本地地址映射）；62个原引擎函数保持。原9音效/1音乐全部精确HTTPS200补齐，使用Windows已有代理单请求读取，不改全局设置，测试站仍直连；首次两份TLS中断和有界补取回执均保留。实际SDK提供者、等待/消息适配函数及包装脚本移出运行包；原界面/美术和Three库保持，内部真实本地存储接回castleTimes与实际关卡进度；本地下一关仅原胜利stars>0才可继续，未伪造账号、支付或星数。完整69事件无外联/游戏资源失败/异常/console警告，仅诊断页延迟favicon.ico404单独保留。未通关，未验证后21关、墙跳/冲刺、暂停/音乐开关、手柄、胜利后本地结果/下一关/最佳时间恢复；刷新仅证明原初始场景恢复，不称存档晋升已测。完整AST核对发现原关卡为22份，原UI的I至V罗马数字并非关卡总数；第5步后仅将本地关卡边界5修正为22，主游戏/引擎均未改，不追加第6步。该未测进度分支与实测首关严格分开。沿原任务正常入库到待验收，未批准未供货。
