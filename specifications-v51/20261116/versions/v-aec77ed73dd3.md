# Retro Bowl 游戏规格说明书

格式版本：V5.1

仅记录有依据的实现层事实；字段非必填。空白表示代码未披露或未登记，不代表不存在、不可玩或验收通过。

## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：Retro Bowl

**玩法类型**

体育 / 模拟

**操作方式**

界面点击按钮/球员卡；场上点击蓝圈跑卫交接跑球，拖拽四分卫瞄准传球并松开出手；跑球中可滑动控制。第四档选择继续进攻、弃踢或射门；射门按原力量条和方向流程。达阵后选择1分或2分。防守解说阶段可点击Activate SIM，经原确认后进入原生模拟，并可Skip Time。Esc可退出教程。实测桌面鼠标，真实触控未测。

**视角与布局**

横向球场侧俯视像素画面；顶部队伍得分、节次/倒计时、档位码数；场内路线、球员圈和成就反馈。管理界面为阵容/设施卡与赛程、战绩、士气栏。

**画面维度**

2D

**引擎**

原生GameMaker HTML5运行时，游戏版本1.6.8.0。

**程序语言**

GameMaker编译JavaScript、HTML；TXT/JSON数据。可编辑发布源码已取得，原作者GameMaker工程未取得。

**结论字段**

- `game_summary` = 在复古像素橄榄球比赛中控制进攻，同时管理球队阵容、设施和赛季生涯。

## 2. 资源类型

**维度定义**：内容元素类别及其引擎资源格式。

**内容说明**

**内容元素资源类型**

4张原PNG纹理页含角色、场景、UI与动画帧；27个原OGG音乐/音效；原TXT语言、球队、赛程、人名、成就与记录模板；GameMaker JSON_game内嵌对象/精灵/房间/脚本数据。

**结论字段**

- `engine_asset_system` = 原JSON_game纹理与声音声明、GameMaker房间和精灵系统；html5game下原数据路径与WebAudio worklet。发布采用OGG能力分支。59份精确恢复含2份仅审计旧平台扩展，交付不执行旧扩展。

## 3. 核心挑战维度

**维度定义**：核心玩法所涉及的挑战类型及主次。

**内容说明**

**核心挑战内容**

在防守压力和有限档数内选择跑球或传球，推进足够码数延续进攻并争取得分；根据阵容、体能和经济资源维持赛季表现。

**结论字段**

- `core_challenge_type` = 操作执行 / 策略规划

## 4. 操控方式

**维度定义**：输入方式、输入元素和操控构成。

**内容说明**

**操作方式**

界面点击按钮/球员卡；场上点击蓝圈跑卫交接跑球，拖拽四分卫瞄准传球并松开出手；跑球中可滑动控制。第四档选择继续进攻、弃踢或射门；射门按原力量条和方向流程。达阵后选择1分或2分。防守解说阶段可点击Activate SIM，经原确认后进入原生模拟，并可Skip Time。Esc可退出教程。实测桌面鼠标，真实触控未测。

**操控构成要素**

点击、持续指针按压、拖拽瞄准/释放；原生确认和取消；赛后采访二选一。

## 5. 行为路径

**维度定义**：玩家在一次核心循环中重复执行的动作顺序。

**内容说明**

**核心玩法**

查看档位/路线→跑球或拖拽传球→原碰撞/接球/擒抱判定→码数与档位更新→达到首攻继续，或达阵/射门/失误/弃踢交换球权→四节结算。

**结论字段**

- `core_loop` = 选择进攻→执行输入→码数/得分反馈→判断下一档→继续进攻或交换球权。

## 6. 游戏路径（关键节点 + 流失风险）

**维度定义**：从启动到结束的流程节点及已披露的风险。

**内容说明**

**游戏流程**

启动读取个人生涯→查看球队与赛程→阵容/设施管理→比赛入口→四节进攻与原生防守模拟→比赛结果/战绩→采访/球员统计→下一周与赛季。新生涯含教学，本轮只完成第一传球阶段，随后原Esc退出。

## 7. 成长路径

**维度定义**：玩家推进和变强的途径。

**内容说明**

**奖励与成长**

比赛与赛后流程改变信用、球迷、士气、球员XP/体能及战绩；信用可升级训练、康复、球场或用于原阵容/职员功能。原季后赛和赛季数据保留，本轮未完成整个赛季循环。

**结论字段**

- `progression_loop` = 参与比赛→得分/结果及XP/信用等结算→管理球员/设施→再进入赛程。统计和结算数值沿用原规则，未免费升级或补发原广告奖励。

## 8. 核心闭环（目标-规则-反馈-激励）

**维度定义**：目标、规则、反馈、激励和下一目标。

**内容说明**

**目标规则反馈激励闭环**

目标：短期推进本档码数、获得首攻或达阵；中期完成比赛争取胜利；长期沿赛程管理球队。规则：原档位、码数、接球/碰撞、失误、计时与加分规则决定球权和比分，防守由原程序处理，SIM由玩家主动确认。反馈：路线/圈选、跑动/擒抱动画、比分和倒计时、档位码数、成就、赛后分节表/战绩/球迷及球员XP。激励：真实赛后原信用和XP、战绩变化；设施升级消耗信用并保留。下一目标：赛后采访、查看球员统计，回球队界面继续下一周。实测27:0和保存闭环；未证明所有赛季/难度或所有奖励分支。音频文件存在并加载，无听觉结论。

## 9. 玩法规则

**维度定义**：核心循环、操作、胜负和结算规则。

**内容说明**

**目标、规则与结算数值**

常规比赛四节，达阵6分，之后选择1分踢球或2分进攻；四档内争取首攻，第四档按位置提供继续、弃踢或射门。场上得分、失误和超时按原引擎判断，不注入分数。SIM启用及SkipTime使用原逻辑，结果如实标记模拟参与。

**已验证流程与未覆盖范围**

保留原GameMaker v1.6.8.0职业橄榄球玩法、球队/球员/赛程/难度/得分/训练经济/原存档格式；7961个原生函数语义SHA一致，JSON_game除SDK Extensions与加载条名外的数据属性一致。退役Poki/CrazyGames实际扩展、广告/推广/外链与宿主依赖，独立原生画布加载条，不注入模拟SDK；可选赛后广告CoinBoost退役且不自动发奖。个人文件仍先读写原localStorage，只阻止不存在个人文件的HTTP回落；PlayerRecords.txt保留为静态原模板。精确恢复59份原资源，其中57份随包、2份旧扩展只留审计；4纹理/27OGG/原US语言和球队等数据齐备。原s_is_co_mode固定返回0；6个学院版专用路径原站404，明确保留缺口，不宣称学院版可用。实际新建Nazeeh Ejiya华盛顿生涯、查看QB/阵容、花2信用升级训练设施；完成传球教程第一阶段后用原Esc退出剩余教程；正式第18周前三节手动跑球/达阵/两分转换/射门尝试/弃踢，第三节防守启用原SIM，第四节原SkipTime结算，最终27:0（分节8/6/6/7），不宣称全手动获胜。原赛后统计/战绩3胜14负/采访承担责任扣1信用；最终信用2、球迷34%、士气74%。刷新仍为原生Y1第18周W27-0、相同战绩/信用2/球迷34%/训练设施2格。整场网络游标过期，旧窗口明确不完整；重新采集刷新及管理界面84条完整事件无截断/外联/404/失败/脚本异常，正式窗口无警告错误，历史故障日志保留。未验证全部赛季/球队/难度/真实触屏/听觉，未供货。
