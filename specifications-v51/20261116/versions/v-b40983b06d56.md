## 1. 基础事实

**维度定义**：游戏类型、操控体验和技术栈。

**内容说明**

- 游戏名称：Plonky - 免费在线玩! | Poki (宝玩)

**玩法类型**

平台跳跃 / 益智

**操作方式**

方向键左/右 → 向左/右移动 → 游戏画面获焦时。
方向键上 → 跳跃 → 满足原起跳条件时。
方向键与跳跃配合 → 越障或跨沟 → 操作过程中。
碰触并推动木架 → 改变物件位置 → 到达对应机关。
点击右上暂停图标 → 打开原暂停菜单 → 游戏中。
点击暂停菜单外观卡 → 请求当前外观项目 → 菜单中。
点击本地领取 → 执行原对应奖励分支 → 确认提示中。
点击取消或Esc → 不领取并返回 → 确认提示中。
绳索等后续机关的完整键位组合未逐项验证，不编造操作。

横向卷轴侧视。角色与机关采用布娃娃/刚体物理表现，镜头随角色推进；横屏与竖屏均实际显示过。右上角暂停，场景箭头提示前进或机关方向。

**画面维度**

2D

**引擎**

Construct 3 HTML5 运行时；Box2D WebAssembly 物理与 Spriter 动画资源。原作者 .c3p 工程未取得。

**程序语言**

JavaScript（运行时、事件脚本与可编辑适配组件）；JSON（原项目配置）；WebAssembly（物理模块）。不据运行包推断原作者工程语言。

**结论字段**

- `game_summary` = 2D 侧视物理解谜平台游戏，以跑跳和刚体机关越障，并通过检查点续玩。
